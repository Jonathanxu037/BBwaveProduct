  • 现有「白名单」有三种含义：参与名单（只有名单内会员能参加）、指定名单（指定会员参加）、奖励档位名单。它们都不是「免除领取限制」的名单，不能直接当作本需求的领取限制白名单。

判断口径

  • 使用：后台可配置，前台有入口、有活动展示，或活动自动发放。废弃：生产代码还在，但前台（含全部按需加载页面）没有该活动的任何入口和请求。未上线：只在 QA 环境有、生产代码中没有，或产品决定暂按未上线处理（幸运转盘，2026-11-13）。
  • IP 限制 / 设备限制：以技术侧对生产代码的梳理为准。「有」表示系统有这套判定（不论当前是否打开）；后台有配置项但系统不读取的，写「无（配置项不生效）」。
  • 白名单：写明名单的作用，便于和本需求的领取限制白名单区分。
