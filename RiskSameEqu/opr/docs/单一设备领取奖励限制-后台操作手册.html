单一设备领取奖励限制 · 活动限制管理操作手册

写给运营和客服：如何在【活动配置 › 活动限制管理】限制同一设备、同一网络（IP）的领取，以及误伤正常玩家时如何处理。789Bingo（老站）、789Games（新站）两个站操作相同，各站分别配置。

重要结论
  • 所有活动的领取限制都在【活动配置 › 活动限制管理】统一配置：列表列出【活动中心】的全部活动，分期的活动每期一行；每个活动（每期）可配置「设备限制」「IP 限制」「白名单导入」三项（N1、N17）。
  • 各活动原有的同 IP、同设备限制上线时沿用原有数据，逐期迁移到活动限制管理，然后删除（如充值活动「同一 IP 每天有 N 个账号可以申领」、新用户转盘「同一台设备只能领取 N 次」），活动配置页上对应的配置项也删除；运营上线后在活动限制管理列表核对迁移结果，「不限制」的行按需补配（N14，见第 04 节）。邀请好友的「同设备不允许互相邀请」和「IP 限制」（同一注册 IP 最多计入 N 个好友）属于邀请资格规则，完成任务砸金蛋同 IP、同设备每天名额属于活动自身规则，都保留。
  • 每个活动（每期）单独配置；不勾选或数量（次数或账号数）填 0，表示不限制；所有活动的限制周期都可选五种，默认「活动期间」（N2、N4）。
  • 活动按领取类型分两类：单次领取类（每个账号只能领一次：绑定手机号码、KYC 认证送彩金、新用户首充、导入用户登录送彩金（789Games 叫登录送彩金活动（白名单）））填「最多领取 N 次」，次数按本活动成功发放的次数统计，同一设备或同一 IP 上的所有账号合计（N3）；多次领取类（一个账号可领多次，如签到、充值优惠、转盘、返水、Crown Rush（皇冠冲榜））填「最多 N 个账号」，每个周期内同一设备、同一 IP 只允许按首次领取成功先后排在前 N 个的账号领取，其他账号领取本活动的任何奖励都被拦截；N=1 即只有首个领取的账号能领（N18）。单个账号能领几次，沿用活动自身规则（N9）。
  • 在「配置限制」弹窗点「保存」后立即生效；活动进行中修改设置，已领取次数和已绑定账号不清零；取消勾选期间发放的次数同样计入；多次领取类重新勾选或调小账号数时，只保留本周期内最先领取的前 N 个账号（N13）。
  • 在活动中心新建或复制生成的新一期，默认沿用同一活动上一期的配置（设备限制、IP 限制、「本活动白名单用户也受此限制」和领取限制白名单），需要不同时到活动限制管理修改，改新一期不影响上一期；没有上一期的期和新建的不分期活动默认不限制。删除的活动或期，配置一起失效，同一活动剩下的期重新编号（N13、N17）。
  • 用户领取、系统自动发放、审核发放、人工发放、批量发放都按配置判定；只触发一次的奖励被拦截后不自动补发（N8、N19）。
  • 所有活动都有「白名单导入」，每个活动（每期）单独导入，导入后点弹窗「保存」才生效；名单内会员不受设备限制、IP 限制（N15）。
  • 活动自身有白名单时，可在弹窗里每项下方设置名单内会员是否也受限制，默认受限制；该设置只在弹窗里显示（N16）。
  • 玩家被限制时看到 "Reward claim limit [编号]"：L01 同设备达上限，L02 同 IP 达上限，L03 取不到设备标识或 IP、无法核验（N6）。

01设置领取限制

菜单路径与权限

【活动配置 › 活动限制管理】，两个站相同（789Games 原来没有【活动配置】菜单的，随本需求新增）。需要「活动限制管理」权限，由平台管理员在后台【权限管理】中分配。

操作步骤

1
进入【活动配置 › 活动限制管理】。列表打开时自动读取活动中心的最新活动和各期；刚在活动中心新建的期没出现时，点「刷新」。
2
找到要配置的活动或某一期：可在「活动名称」下拉中选择活动后点「搜索」，只显示该活动的全部行（分期的活动为其各期）；选「全部」显示全部活动。
3
点该行的「配置」，打开「配置限制」弹窗。在「设备限制与 IP 限制」区勾选要限制的项，选限制周期，再填数量：单次领取类填「最多领取 N 次」，多次领取类填「最多 N 个账号」。需要放行个别会员时，在「白名单导入」区导入名单（第 02 节）。
4
点「保存」，提示「保存成功」后立即生效，列表该行显示新配置；次数或账号数为空、或不是 0–999999 的整数时不能保存。点「取消」或右上角「×」不保存本次对设备限制、IP 限制的修改，本次导入的白名单也不生效。

02导入白名单

位置

「配置限制」弹窗的「白名单导入」区，所有活动都有，沿用后台现有的白名单导入功能。分期的活动每期单独导入，只对本活动（本期）生效；名单内会员不受设备限制、IP 限制，活动自身规则照常。

操作步骤

1
在列表找到活动或某一期，点「配置」。
2
在「白名单导入」区点「导入文件」，按现有模板上传名单，查看导入结果。
3
点弹窗「保存」，名单才生效，列表「白名单导入」列显示「已导入 N 人」；点「取消」或右上角「×」，本次导入不生效。
4
查看当前名单：在弹窗里点「已导入文件下载」。

04上线后核对迁移结果

上线后在列表核对：进入【活动配置 › 活动限制管理】，每个活动（每期）一行，「设备限制」「IP 限制」「白名单导入」三列显示当前配置，迁移结果就显示在这里。按 PRD 5.1 活动表「原有限制」列和上表迁移规则逐个活动、逐期对照：

  1. 显示「不限制」的行（原来没有限制、原配置不生效或关闭、读不到原有限制配置的）：需要限制的，点「配置」补配后保存。
  2. 原数值明显偏大（如每日首充 1000、新用户首充 10000、新站新用户转盘迁移后的 999999）的：按活动参与规模重新设置。
  3. 新站新用户转盘：核对迁移进来的领取限制白名单。

迁移后按本栏目判定：严格按设置的数量判定；需判定的 IP 取不到时拦截（L03）；只统计上线后的领取；新用户转盘按账号数和设备标识判定；789Games 输返活动自动发放也判定。迁移记录可在【日志管理 › 操作日志】查看，操作人为「系统」。

回滚：只想关闭某项限制时，在活动限制管理取消勾选并保存，不需要发版。迁移前系统保存了各活动（期）原有同 IP、同设备限制的配置记录；需要回退版本时，各活动原有限制按记录恢复为上线前的配置，运营到各活动配置页核对（N14）。

常见问题

以前在活动配置页里设置的同 IP、同设备限制去哪了？
上线时生效且已开启的限制按生产环境配置迁移到【活动配置 › 活动限制管理】，原配置项删除，以后统一在这里设置（N14）。活动自身的其他规则（单账号领取次数、同一手机号只能领一次、邀请好友的「同设备不允许互相邀请」和「IP 限制」、新用户转盘按名单发指定奖励、参与名单和指定名单）不变。
在活动中心新建了一期，活动限制管理里没看到？
点「刷新」或重新进入栏目。新一期默认沿用该活动上一期的配置和领取限制白名单，需要不同时点「配置」修改。
删除了一期，期数怎么变了？
期数按现有各期的创建先后编号，删除某一期后剩下的期重新编号；被删除那一期的配置一起失效。
玩家截图里的 L01、L02、L03 是什么？
L01：同设备达上限；L02：同 IP 达上限；L03：暂时取不到设备标识或 IP，无法核验。回复口径见客服 QA。
家人共用设备、同一 Wi-Fi 的正常玩家被拦截怎么办？
核实后把会员导入该活动（期）的领取限制白名单，所有活动适用（N15、N16 ⑦）。误伤较多时，调大次数或账号数，或取消勾选。
线下投注站代办的会员怎么处理？
投注站多名会员共用设备和网络，会被大面积拦截。确认是投注站代办的会员后，直接导入该活动（期）的领取限制白名单。
被拦截的一次性奖励（KYC 认证送彩金、绑定手机号码）能补发吗？
系统不自动补发，调大次数或加白名单后也不会补发已拦截的那一次。核实确属误伤需要补发时，走现有【修改余额审批】人工加款。
审核发放、人工发放、批量发放也会被限制吗？
会（N19）。
① 审核发放：玩家申请时被拦截，不生成申请，玩家看到「奖励领取限制[编号]」；审核通过时被拦截，【派奖审核】和该活动「活动统计」的这条记录显示「奖励领取限制[编号]」，默认不发放，玩家的申请记录为「未通过」。审核人核实后可以强制通过，强制通过的照常发放，不解除已有的绑定：单次领取类计入该设备和 IP 的次数；多次领取类只放行这一次，该账号不加入已绑定账号，之后再领取仍按限制判定。转盘、抽奖类活动只在转动前判定，中奖后进入派奖审核的，审核时不再判定。
② 人工发放、批量发放：被拦截的记录不发放，显示原因，不随批量发出；不能强制发放，确需发放的走现有【修改余额审批】人工加款。
多次领取类活动勾选后，同一设备上的其他账号还能领吗？
按填写的「最多 N 个账号」：每个周期内按首次领取成功的先后，前 N 个在该设备（或 IP）领取的账号与之绑定，可以按活动规则继续领取；前 N 个已满时，其他账号领取本活动的任何奖励都被拦截。例如设「每天 · 最多 2 个账号」，账号 A、B 当天先在设备 X 领取后，账号 C 当天在设备 X 领取被拦截。「每天」「一个月」在下一个周期开始时清空已绑定账号；「7 天」「15 天」按滚动窗口，例如选「7 天 · 最多 1 个账号」，账号 A 最后一次在设备 X 领取是 2026-11-04，账号 B 在 2026-11-10 领取被拦截，2026-11-11 可以领取；「活动期间」整个活动期间累计。家人共用设备时，账号数设得过小会拦住其他家庭成员，误伤按白名单处理。
IP 限制的次数或账号数设多少合适？
移动网络下，大量用户可能共用一个出口 IP。请按活动参与规模设置，宁可设大，不要设小。多次领取类勾选 IP 限制后，同一网络下每个周期只有前 N 个账号能领，账号数请按共用规模设置。
活动原有的名单（参与名单、指定名单、指定奖励名单）里的会员也受限制吗？
默认受限制。如需让名单内会员不受某一项限制，在配置弹窗取消该项下方的「本活动白名单用户也受此限制」并保存；设备限制、IP 限制分别设置。名单较大或来源不可靠时不建议取消，否则名单内的小号可以绕过限制。只想放行个别误伤会员时，用「白名单导入」。
白名单会员能无限领取吗？
不能。白名单只免除设备限制、IP 限制，活动自身规则照常；其领取仍计入该设备和该 IP 的次数（多次领取类计入已绑定账号数），同一设备上的其他账号照常受限。
活动进行中把次数或账号数改小了，已领的会收回吗？
不会。已发放的奖励不受影响；已领取次数和已绑定账号不清零，之后按新设置判断。
多次领取类活动已经在被刷，进行中才勾选限制或调小账号数，已经在领的账号还能领吗？
只保留本周期内最先在该设备（或 IP）领取的前 N 个账号，其余账号从保存起领取被拦截（L01 / L02），可立即止损。「前 N 个」按各账号本周期内首次领取成功的时间先后确定；之后调大账号数时按同一顺序放开。例如不限制期间账号 A、B、C 先后在设备 X 领取，勾选「活动期间 · 最多 1 个账号」并保存后只有 A 能继续领取。被拦住的正常玩家核实后导入领取限制白名单（N13 ③）。
活动已结束或已关闭，还能配置吗？删除的活动呢？
已结束、已关闭的活动（期）照常列出，可以配置，对之后的领取生效。在活动中心删除的活动或期从列表消失，配置一起失效。
自动发放的活动也会被限制吗？
会。超过上限的账号本次不发放，也不提示；首页奖励弹窗、站内信、推送、短信、聊天室播报都不触发。设备和 IP 取账号最近一次登录的记录，取不到时也不发放（N8）。
充值后的优惠和转盘被限制时会怎样？
充值页可选的优惠（充值活动、新用户充值活动计划）：选择时已达上限会置灰；到账时再判定一次，超过时只到账本金，不通知。每日首充、新用户首充：到账或完成 KYC 后自动发放，按自动发放判定。老用户充值转盘、返现充值转盘：被拦截时不给转盘次数、不弹出转盘、不提示，充值金额照常到账（N7）。
谁改了限制配置，在哪里查？能查拦截记录吗？
配置修改记录在【日志管理 › 操作日志】查（操作人、时间、活动名称、期数和该期的活动名称、修改前后的配置；上线迁移的操作人为系统）。删除某一期后期数会重新编号，按该期的活动名称核对是哪一期；本版没有拦截记录查询页，需要时找技术。
