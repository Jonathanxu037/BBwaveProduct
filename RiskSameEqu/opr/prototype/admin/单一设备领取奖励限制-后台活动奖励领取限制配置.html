规则批注

  1. 适用范围：所有活动（含以后新增）的配置页都有本板块，位于现有配置之后、「保存」之前；用户领取和系统自动发放都按配置判定。PRD 规则 N1 · F02-01 活动奖励领取限制板块
  2. 三项配置：同设备、同 IP、同账户，每项有勾选框、限制周期（活动期间 / 每天 / 7 天 / 15 天 / 一个月）、最多领取次数；不勾选或填 0 为不限制；新建时不勾选。PRD 规则 N2、N4
  3. 次数口径：按本活动成功发放的次数统计，同设备、同 IP 为所有账号合计，同账户为该账号自己；不同活动分别计算。PRD 规则 N3
  4. 保存校验：勾选后次数必填，为 0–9999 的整数；为空「请输入最多领取次数」，不合法「请输入 0–9999 的整数」，均不能保存。演示：清空次数或填 1.5 后点「保存」。PRD 规则 N13 ①
  5. 生效：随活动保存后立即生效；活动进行中修改，已领取次数不清零；复制活动时一起复制。PRD 规则 N13 ②–④
  6. 领取限制白名单：只对本活动生效；名单内会员跳过同设备、同 IP，同账户和活动现有规则照常，其领取仍计入设备和 IP 次数。添加、移除立即生效；创建配置页需先保存活动（按钮置灰）。弹窗高度为页面 3/4，表格在弹窗内滚动。演示：输入 nouser 看「会员账号不存在」，输入列表已有账号看「该会员已在白名单中」。PRD 规则 N15 · F02-03 领取限制白名单
  7. 新用户转盘：去掉原有设备、IP 两项；设备项迁移为「同设备 · 活动期间 · 原值」，IP 项口径不同不迁移。PRD 规则 N14 · F02-02 新用户转盘原配置并入
