单一设备领取奖励限制 · 活动奖励领取限制配置操作手册

写给运营和客服：怎么限制同一设备、同一网络的领取次数，误伤时怎么处理。

打开后台原型 ›查看 PRD ›
重要结论
  • 每个活动单独配置同设备、同 IP；不勾选或次数填 0 为不限制（PRD 3.2 本需求规则 N2）。
  • 次数按本活动成功发放的次数统计，设备或网络上所有账号合计；单个账号的次数沿用活动自身规则（N3、N9）。
  • 点活动「保存」后生效；活动进行中修改，已领取次数不清零（N13）。
  • 白名单沿用现有白名单导入，按活动导入，保存后生效；名单内会员不受这两项限制（N15）。
  • 玩家被限制时看到「Reward claim limit [编号]」：L01 同设备、L02 同 IP、L03 无法核验（N6）。
  • 新用户转盘上线当天，需按新口径填写同 IP 项（N14）。

01设置领取限制

菜单路径与权限

【活动中心 › 任一活动】配置页的「活动奖励领取限制」板块。有列表的活动点「创建活动」或「修改」（新用户转盘为「编辑」）进入；无列表的活动进入菜单即是配置页。权限沿用现有。

字段说明

字段含义默认值
同设备 / 同 IP勾选要限制的项，按该设备或网络上所有账号合计不勾选
限制周期活动期间：开始到结束累计；每天：每天 00:00 重算；7 天 / 15 天：含当天往前滚动累计；一个月：自然月，每月 1 日重算（GMT+8）活动期间
最多领取次数0–9999 的整数，0 为不限制；勾选后必填-

操作步骤

1
勾选要限制的项，选限制周期，填最多领取次数。
2
点「保存」，提示「保存成功」即生效；次数为空或不是 0–9999 的整数时不能保存。

02导入白名单

菜单路径与权限

同一板块最后一行，沿用后台现有的白名单导入。只对本活动生效。

操作步骤

1
点「导入文件」，按现有模板上传名单，查看导入结果。
2
点活动「保存」，白名单生效；不保存不生效。
3
查看当前名单：点「已导入文件下载」。

03新用户转盘上线处理

菜单路径与权限

【活动中心 › 新用户转盘活动】的修改页。

操作步骤

1
核对设备项：原「同一台设备只能领取 N 次」已迁移为「同设备 · 活动期间 · N 次」。
2
原白名单导入和已导入名单保留，即本活动的领取限制白名单。
3
上线当天填写同 IP 项：原「同一注册 IP 累计最多计入 N 个账号」不迁移，按新口径（领取 IP 的领取次数）勾选、填次数并保存；填写前没有 IP 限制。

常见问题

玩家截图里的 L01、L02、L03 是什么？
L01：同设备达上限；L02：同 IP 达上限；L03：暂时无法核验设备或网络。回复口径见客服 QA。
家人共用设备、同一 Wi-Fi 的正常用户被拦截怎么办？
核实后导入该活动的白名单并保存；误伤多时调大次数或取消勾选。
同 IP 次数设多少合适？
移动网络下大量用户可能共用一个出口 IP，按活动参与规模设置，宁大勿小。
同设备现在能用吗？
现有设备标识能否唯一区分一台手机待技术确认（PRD Q3），确认前不建议勾选。
抽奖、每日首充原有的同 IP 配置和新的同 IP 项有什么区别？
原配置限制同一 IP 每天参与的账号数，新项限制同一 IP 的领取次数；都保留，都满足才能领取，避免重复设置同一意图。
白名单会员能无限领取吗？
不能。只免同设备、同 IP 限制，活动自身规则照常；其领取仍计入设备和网络次数，同设备上的其他账号照常受限。
活动进行中把次数改小了，已领的会收回吗？
不会。已发放不受影响，之后按新次数判断，已领取次数不清零。
自动发放的活动也会被限制吗？
会。超过次数的账号本次不发放，无提示。
谁改了限制配置，在哪里查？能查拦截记录吗？
配置修改查【日志管理 › 操作日志】；本版没有拦截记录查询页，需要时找技术。
