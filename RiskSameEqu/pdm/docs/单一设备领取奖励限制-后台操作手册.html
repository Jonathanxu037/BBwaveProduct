写给运营和客服：怎么设置活动的同设备、同 IP、同账户领取次数，误伤正常用户时怎么处理。

打开后台原型 ›查看 PRD ›
重要结论
  • 每个活动自己配置，不勾选或次数填 0 为不限制；没有全平台总开关（PRD 3.2 本需求规则 N2）。
  • 次数按本活动成功发放的次数统计：同设备、同 IP 是所有账号合计，同账户是该账号自己（N3）。
  • 随活动点「保存」后立即生效；活动进行中修改，已领取次数不清零（N13）。
  • 每个活动有自己的领取限制白名单：名单内会员不受同设备、同 IP 限制，同账户照常；添加、移除后立即生效，不用再点活动的「保存」（N15）。
  • 新用户转盘原有的设备、IP 两项并入本板块；同 IP 口径已变，上线当天需立即填写（N14）。

01设置活动奖励领取限制

菜单路径与权限

【活动中心 › 任一活动】的配置页，「活动奖励领取限制」板块（现有配置之后、「保存」之前）。权限沿用该活动页面现有权限。

字段说明

字段含义默认值
同设备 / 同 IP / 同账户勾选要限制的项；同设备、同 IP 按该设备或网络上所有账号合计，同账户按该账号自己不勾选
限制周期活动期间：活动开始到结束累计；每天：每天 00:00（GMT+8）重新计算；7 天 / 15 天：含当天往前 7 / 15 天内累计，每天滚动；一个月：按自然月累计，每月 1 日 00:00 重新计算活动期间
最多领取次数0–9999 的整数，填 0 为不限制；勾选后必填-

操作步骤

1
进入【活动中心】打开活动配置页：有列表的活动点「创建活动」或该行「修改」（新用户转盘活动为「编辑」）；无列表的活动，进入菜单即为配置页。
2
勾选要限制的项，选择限制周期，填写最多领取次数。
3
点「保存」，提示「保存成功」后立即生效。次数为空或不是 0–9999 的整数时不能保存。

02领取限制白名单

菜单路径与权限

活动配置页「活动奖励领取限制」板块最后一行，点「管理白名单」。只对本活动生效。

字段说明

字段含义默认值
会员账号要加入白名单的会员名（与后台会员列表一致），必填-
备注加入原因，选填，最多 100 个字-
添加时间 / 操作人系统自动记录，时间为 GMT+8-

操作步骤

1
添加：在弹窗上方填写会员账号和备注，点「添加」，提示「添加成功」。
2
查询：输入会员账号点「查询」，点「重置」看全部；移除：在该行点「移除」并确认。
3
添加、移除后立即生效，直接关闭弹窗。新建活动需先保存活动，才能配置白名单。

03新用户转盘上线前处理

菜单路径与权限

【活动中心 › 新用户转盘活动】的修改页面。

操作步骤

1
上线后原「同一台设备只能领取 N 次」已自动迁移为「同设备 · 活动期间 · N 次」，打开核对。
2
原「同一注册 IP 累计最多计入 N 个账号」不迁移。上线当天按新口径（领取时的 IP 统计领取次数）勾选同 IP、填写次数并保存；填写前新用户转盘没有 IP 限制。

常见问题

家人共用设备、同一 Wi-Fi 的正常用户被拦截怎么办？
核实后把会员加入该活动的领取限制白名单，添加后立即生效；误伤人数多时，调大次数或取消勾选。
同 IP 次数设多少合适？
移动网络下大量用户可能共用一个出口 IP，次数要按活动参与规模设置，宁大勿小；不确定时先只用同设备、同账户。
同设备现在能用吗？
现有设备标识能否唯一区分一台手机还在等技术确认（PRD Q3），确认前不建议勾选同设备。
抽奖、每日首充原有的同 IP 配置和新的同 IP 项有什么区别？
原有配置限制同一 IP 每天能参与的账号数，新的同 IP 项限制同一 IP 的领取次数；两者都保留，都满足才能领取。配置时避免重复设置同一意图。
谁改了限制配置或白名单，在哪里查？
【日志管理 › 操作日志】，记录操作人、时间和活动。
把会员 B 加入白名单后，同一设备上的会员 C 也能领了吗？
不能。白名单只对名单里的会员生效；B 领取后同样计入这台设备的次数，C 仍按限制判断。
白名单会员能无限领取吗？
不能。白名单只免同设备、同 IP 限制，同账户次数和活动自身规则照常。
活动进行中把次数改小了，已经领过的会被收回吗？
不会。已发放的奖励不受影响；之后按新次数判断，已领取次数不清零。
自动发放的活动也会被限制吗？
会。勾选后，超过次数的账号本次不发放，玩家不会收到提示。
能查到某次领取被拦截的记录吗？
本版没有拦截记录查询页，需要时找技术查询。
