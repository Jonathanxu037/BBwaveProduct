单一设备领取奖励限制 · 活动奖励领取限制配置操作手册

写给运营和客服：如何限制同一设备、同一网络（IP）的领取，以及误伤正常玩家时如何处理。789Bingo（老站）、789Games（新站）两个站操作相同，各站分别配置。

重要结论
  • 活动分四种接入方式：A 同设备、同 IP 两项 + 领取限制白名单；B 两项，沿用活动原有白名单；C 只有同设备，同 IP 仍在活动原有条件里设置；D 不改（新用户转盘、完成任务砸金蛋）。各站各活动的方式见第 03 节，由技术固定，运营不能切换（N17）。
  • 每个活动单独配置；不勾选或次数填 0，表示不限制（N2）。
  • 活动按领取类型分两类：单次领取类（每个账号只能领一次：绑定手机号码、KYC 认证送彩金、新用户首充、导入用户登录送彩金（789Games 叫登录送彩金活动（白名单）））设最多领取次数，次数按本活动成功发放的次数统计，同一设备或同一 IP 上的所有账号合计（N3）；多次领取类（一个账号可领多次：签到、充值优惠、转盘、返水、闯关）不设次数，勾选后每个周期内同一设备、同一 IP 只允许首个领取的账号领取，其他账号领取本活动的任何奖励都被拦截（N18）。单个账号能领几次，沿用活动自身规则（N9）。
  • 点活动「保存」后生效；活动进行中修改设置，已领取次数不清零；取消勾选期间发放的次数同样计入（N13）。
  • 用户领取、系统自动发放、审核发放、人工发放、批量发放都按配置判定；只触发一次的奖励被拦截后不自动补发（N8、N19）。
  • 只有 A 方式的活动有领取限制白名单，每个活动单独导入，保存后生效；名单内会员不受同设备、同 IP 限制（N15）。
  • 活动自身有白名单时，可在每项下方设置名单内会员是否也受限制，默认受限制（N16）。
  • 玩家被限制时看到 "Reward claim limit [编号]"：L01 同设备达上限，L02 同 IP 达上限，L03 取不到设备标识或 IP、无法核验（N6）。
  • C 方式的活动先按原有 IP 条件判断（被拦截时沿用活动现有提示），通过后再判断同设备，因此不会出现 L02（N5、N17）。

01设置领取限制

菜单路径与权限

【活动中心 › 任一活动】配置页的「活动奖励领取限制」板块。有列表的活动，点「创建活动」或「修改」（部分活动为「编辑」）进入；没有列表的活动，进入菜单就是配置页。D 方式的活动没有本板块；【活动配置】栏目不涉及。权限沿用该活动页面现有权限。

字段说明

字段含义默认值
同设备 / 同 IP（C 方式只有同设备）勾选要限制的项。单次领取类：次数按该设备或该 IP 上所有账号合计；多次领取类：每个周期内只允许首个领取的账号领取不勾选
限制周期活动期间：本功能上线后，活动开始到结束累计；每天：每天 00:00 重新计算；7 天 / 15 天：含当天往前 7 / 15 天滚动累计；一个月：按自然月，每月 1 日 00:00 重新计算（GMT+8）。多次领取类的绑定：「每天」「一个月」在下一个周期开始时解除；「7 天」「15 天」按滚动窗口，领取当天往前 7 / 15 天内该设备（或 IP）有其他账号领过就拦截，没有就可以领取并成为新的绑定账号；「活动期间」整个活动期间一直绑定。C 方式活动沿用原有 IP 限制的周期，固定为「每天」，不能选；新用户首充（单次领取类）例外，可选五种周期活动期间（C 方式固定为每天；新用户首充默认活动期间）

操作步骤

1
勾选要限制的项，选限制周期（C 方式活动固定为「每天」，沿用活动原有限制的周期，不能选；新用户首充例外，可选五种周期，默认「活动期间」）；单次领取类活动再填最多领取次数。
2
点「保存」，保存成功后立即生效；次数为空，或不是 0–9999 的整数时，不能保存。

02导入白名单

菜单路径与权限

只有 A 方式的活动有领取限制白名单，在本板块最后一行，沿用后台现有的白名单导入功能，只对本活动生效。B、C 方式没有领取限制白名单，沿用活动原有名单，通过每项下方的「本活动白名单用户也受此限制」决定名单内会员是否受限。

操作步骤

1
点「导入文件」，按现有模板上传名单，查看导入结果。
2
点活动「保存」后白名单生效；不保存则不生效。
3
查看当前名单：点「已导入文件下载」。

常见问题

玩家截图里的 L01、L02、L03 是什么？
L01：同设备达上限；L02：同 IP 达上限；L03：暂时取不到设备标识或 IP，无法核验。回复口径见客服 QA。
家人共用设备、同一 Wi-Fi 的正常玩家被拦截怎么办？
A 方式的活动：核实后把会员导入领取限制白名单，并保存活动。B、C 方式的活动没有领取限制白名单，不能只放行某一个会员，按活动类型处理（N16 ⑦）：
① 已启用指定名单的活动：把会员加入活动原有名单，并取消对应项下方的「本活动白名单用户也受此限制」。名单内全部会员都不再受该项限制，且获得名单原有的资格。活动面向全部会员、未启用指定名单时，不要为放行误伤会员启用名单（启用后名单外会员可能无法参加），改为调大次数或取消该项勾选。
② 参与名单类活动（789Bingo 的导入用户登录送彩金、新用户充值活动计划；789Games 的登录送彩金活动（白名单）、新用户充值活动计划）：名单内就是全部参与者，取消勾选等于该项对整个活动失效。
③ 没有自身名单的活动（789Bingo 的新盈利活动 V2、邀请好友；789Games 的新输返活动、邀请好友活动）：只能调大次数或取消该项勾选。
误伤较多时，调大次数或取消勾选。
线下投注站代办的会员怎么处理？
投注站多名会员共用设备和网络，会被大面积拦截。确认是投注站代办的会员后直接加白名单：A 方式导入领取限制白名单；B、C 方式按上一问的三种情况处理。
被拦截的一次性奖励（KYC 认证送彩金、绑定手机号码）能补发吗？
系统不自动补发，调大次数或加白名单后也不会补发已拦截的那一次。核实确属误伤需要补发时，走现有【修改余额审批】人工加款。
审核发放、人工发放、批量发放也会被限制吗？
会（N19）。
① 审核发放：玩家申请时被拦截，不生成申请，玩家看到「奖励领取限制[编号]」；审核通过时被拦截，【派奖审核】和该活动「活动统计」的这条记录显示「奖励领取限制[编号]」，默认不发放，玩家的申请记录为「未通过」。审核人核实后可以强制通过，强制通过的照常发放并计入该设备和 IP 的次数，不改变已有的绑定。转盘、抽奖类活动只在转动前判定，中奖后进入派奖审核的，审核时不再判定。
② 人工发放、批量发放：被拦截的记录不发放，显示原因，不随批量发出；不能强制发放，确需发放的走现有【修改余额审批】人工加款。
多次领取类活动勾选后，同一设备上的其他账号还能领吗？
不能。每个周期内首个在该设备（或 IP）领取的账号与之绑定，其他账号领取本活动的任何奖励都被拦截。「每天」「一个月」在下一个周期开始时解除绑定；「7 天」「15 天」按滚动窗口，例如选 7 天，账号 A 最后一次在设备 X 领取是 2026-11-04，账号 B 在 2026-11-10 领取被拦截，2026-11-11 可以领取；「活动期间」一直绑定。家人共用设备时，其他家庭成员整个周期都领不到，误伤按白名单处理。
同 IP 次数设多少合适？
移动网络下，大量用户可能共用一个出口 IP。请按活动参与规模设置，宁可设大，不要设小。多次领取类勾选同 IP 后，同一网络下每个周期只有一个账号能领，请谨慎勾选。
C 方式活动（如充值活动、每日首充）的同 IP 在哪里设？
仍在活动原有条件「同一 IP 每天有 N 个账号可以申领」里设置，限制的是账号数；新板块只有同设备。上线时请把原有数值调到合理值（如每日首充现为 1000、新用户首充现为 10000），否则设备标识被伪造时没有其他兜底。注意：充值类条件里的「同一 IP 每天仅领 N 次」、新用户充值活动计划的「每天同 IP 次数」目前都不生效（后者由技术确认：生效则按 C 方式做，不生效改为 A 方式、在新板块设置同 IP，PRD Q8 ③）。签到属于 A 方式，同 IP 在新板块设置，原「相同 IP 可领账号个数」不生效。各活动原有的限制见《活动中心现状清单》。
活动原有的名单（参与名单、指定名单、指定奖励名单）里的会员也受限制吗？
默认受限制。如需让名单内会员不受某一项限制，取消该项下方的「本活动白名单用户也受此限制」并保存；同设备、同 IP 分别设置。名单较大或来源不可靠时不建议取消，否则名单内的小号可以绕过限制。A 方式的活动只想放行个别误伤会员时，用「领取限制白名单」导入。
白名单会员能无限领取吗？
不能。白名单只免除同设备、同 IP 限制，活动自身规则照常；其领取仍计入该设备和该 IP 的次数，同一设备上的其他账号照常受限。
活动进行中把次数改小了，已领的会收回吗？
不会。已发放的奖励不受影响；已领取次数不清零，之后按新次数判断。
自动发放的活动也会被限制吗？
会。超过次数的账号本次不发放，也不提示；首页奖励弹窗、站内信、推送、短信、聊天室播报都不触发。设备和 IP 取账号最近一次登录的记录，取不到时也不发放（N8）。
充值后的优惠和转盘被限制时会怎样？
充值页可选的优惠（充值活动、新用户充值活动计划）：选择时已达上限会置灰；到账时再判定一次，超过时只到账本金，不通知。每日首充、新用户首充：到账或完成 KYC 后自动发放，按自动发放判定。老用户充值转盘、返现充值转盘：被拦截时不给转盘次数、不弹出转盘、不提示，充值金额照常到账（N7）。
谁改了限制配置，在哪里查？能查拦截记录吗？
配置修改记录在【日志管理 › 操作日志】查；本版没有拦截记录查询页，需要时找技术。
