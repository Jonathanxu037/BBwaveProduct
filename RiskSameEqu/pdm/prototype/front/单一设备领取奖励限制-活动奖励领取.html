规则批注

  1. 按活动配置判定：只判断本活动已勾选且次数大于 0 的项，某项已领取次数 ≥ 最多领取次数即拦截。PRD 规则 N2、N3、N4 · F01-01 领取次数限制判定
  2. 判定顺序：活动现有校验（含单账号次数）通过后，按 同设备 → 同 IP 判断，只提示第一项不通过的。PRD 规则 N5、N9
  3. 拦截：不发放、不扣参与次数，按钮保持可点，转盘和抽奖在转动前拦截；Toast「奖励领取限制[编号]」：L01 同设备达上限、L02 同 IP 达上限。PRD 规则 N6 · F01-02 拦截处理与提示
  4. 充值优惠：选择时超过上限 → 优惠置灰并显示「奖励领取限制[编号]」，可不选优惠充值（见「充值页」场景）；到账时超过 → 不发优惠，充值照常到账。PRD 规则 N7
  5. 取不到设备标识或 IP：需判定同设备或同 IP 时取不到，不发放、不扣次数，Toast「奖励领取限制[L03]」。PRD 规则 N11 · F01-03 设备标识或 IP 获取失败处理
  6. 领取限制白名单：名单内会员跳过同设备、同 IP 判定；其领取仍计入设备和 IP 的次数。PRD 规则 N15
  7. 自动发放：发放前同样判定，超过的账号本次不发放，无提示。PRD 规则 N8
  8. 本版不考虑的识别情况：换浏览器、在浏览器和 App 之间切换、清除缓存或重装 App 后被识别成新设备，以现有标识结果为准；对接三方风控服务后优化。PRD 规则 N10
