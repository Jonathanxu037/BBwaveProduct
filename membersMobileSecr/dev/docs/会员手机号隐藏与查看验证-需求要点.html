会员手机号隐藏与查看验证 · 需求要点 · v1.0

版本：v1.0站点：789Bingo【B】、789Games【G】端：管理后台依据：需求开发 PRD 文档

一句话需求

在两站管理后台【用户管理 › 会员】列表「会员信息」卡片的「手机号」一行，由后端按「前 3 位 + **** + 后 4 位」脱敏后再给页面显示；点号码后的闭眼图标并通过本人谷歌身份验证后，显示该会员的完整号码，点睁眼恢复脱敏；查看记入操作日志。

业务流程

1
进入会员列表：显示「091****1234」+ 闭眼图标
↓
2
点闭眼图标：谷歌身份验证弹窗 → 输入 6 位验证码
↓
3
验证通过：记入操作日志 → 返回并显示完整号码，图标变睁眼
↓
4
恢复脱敏：点睁眼，或刷新、翻页、查询

开发功能点

F01-01脱敏显示查看 PRD ›

要做什么
  • 后端返回脱敏号码，页面和返回数据里没有完整号码。
公式
去掉国码和符号后 ≥ 8 位 → 前 3 位 + **** + 后 4 位
不足 8 位 → ****
未绑定 → -
涉及端
后端后台前端

F02-01验证查看查看 PRD ›

要做什么
  • 号码后加闭眼图标，点击弹出谷歌身份验证弹窗。
  • 通过：显示该会员完整号码，图标变睁眼。
  • 不通过：号码保持脱敏，提示沿用《后台谷歌验证码加固》需求。
  • 点睁眼、刷新、翻页、查询恢复脱敏。
公式
显示完整号码 ＝ 本人谷歌验证码校验通过
涉及端
后台前端后端

公式
无
