适用范围 Scope

789Bingo 游戏内浮动侧栏上的流水闯关（Crown Rush）入口，适用所有期流水闯关活动（第一个适用的是圣诞这一期）。适用 H5、iOS App、安卓 App；PC 和旧版安卓原生 App 没有这个入口。H5 在圣诞活动预热开始前上线，App 在包含此功能的新版本上线后才有。按钮文字为 Quest（以上线界面为准），下文称 Quest 按钮。
The Crown Rush shortcut on the floating in-game sidebar of 789Bingo, for every Crown Rush event (starting with the Christmas one). Available on H5, iOS app and Android app; not available on PC or the old native Android app. H5 goes live before the Christmas event warm-up starts; the apps show it only after updating to the version that includes it. The button label is "Quest" (as shown in the live app); it is called the Quest button below.

这次改了什么 What changed

玩家在游戏中展开侧栏（点 G 图标），会在 Reload 和 G 图标之间看到 Quest 按钮。点它会像点 Home 一样先离开游戏，再打开 Crown Rush 活动页；同时有几期活动开着时（一般不会出现），打开其中最新的那一期。只要有一期活动处于预热中、进行中或领奖期就显示，所有期都下架后自动隐藏。活动规则和奖励没有任何变化。
When players open the in-game sidebar (tap the G icon), they see a Quest button between Reload and the G icon. Tapping it leaves the game just like Home, then opens the Crown Rush event page; if several Crown Rush events are running, it opens the newest one. It shows as long as any Crown Rush event is in warm-up, live or claim window, and is hidden automatically after all of them are taken down. Event rules and rewards are unchanged.

客服核查步骤 How to check

  1. 问端和版本：玩家用 H5、iOS 还是安卓 App；App 是否已更新到最新版本。PC 和旧版 App 没有这个按钮。
    Ask device and version: H5, iOS or Android app; whether the app is updated to the latest version. PC and older app versions do not have this button.
  2. 看活动阶段：对照各期 Crown Rush 活动时间，判断有没有一期处于预热中、进行中或领奖期；所有期都下架后按钮不显示。
    Check the event period: compare with the schedules of all Crown Rush events to see whether any is in warm-up, live or claim window; the button is hidden after all of them are taken down.
  3. 问是否展开侧栏：按钮在侧栏里，侧栏收起时只看到 G 图标。
    Ask whether the sidebar is open: the button is inside the sidebar; when collapsed, only the G icon shows.
  4. 注单问题：查玩家投注记录，离开游戏时的注单按平台现有规则结算，与点 Home 相同。
    Bet questions: check the player's betting history; bets are settled under the platform's existing rules when leaving the game, the same as tapping Home.
