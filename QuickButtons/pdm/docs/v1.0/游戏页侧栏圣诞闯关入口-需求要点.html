游戏页侧栏圣诞闯关入口-v1.0-需求要点 · 迅速版

版本：v1.0端：H5（网页版）、iOS、Flutter 安卓（苹果、安卓 App）依据：需求开发 PRD 文档

一句话需求

在老站 789Bingo 游戏页浮动侧栏（H5、iOS、Flutter 安卓）的 Reload 与 G 图标之间新增 Quest 按钮：圣诞这一期流水闯关处于预热中、进行中或领奖期时显示，下架后自动隐藏；点击后按 Home 的方式离开游戏，进入圣诞这一期落地页。侧栏其他按钮和活动本身的规则、页面均不变。

业务流程

1
进入游戏：任意一个带侧栏的游戏
↓
2
打开侧栏：圣诞这一期开着，就看到按钮
↓
3
点按钮：和点 Home 一样先退出游戏
↓
4
进落地页：活动在哪个阶段就显示哪个阶段的页面
A - 圣诞这一期开着

显示按钮开着 = 预热中、进行中或领奖期

B - 没开、已下架或被挂起且不展示公告

不显示按钮别的期开着也不显示

C - PC、老版本 App、安卓原生老包

不显示按钮侧栏和现在一样

开发功能点

F01-01入口位置与样式查看 PRD ›

HomeDepositReloadQuestG
要做什么
  • 按钮放在 Reload 和 G 图标中间，文字 Quest。
  • 新画一个图标，和旁边按钮一个风格、一样大。
  • 不加红点角标，不闪不跳；不能有金额和 FREE、WIN 这类词。
  • 看得到 G 图标的人就看得到按钮。
公式
无
涉及端
H5iOSFlutter 安卓

F01-02入口显示时机查看 PRD ›

要做什么
  • 每次打开侧栏时，只看圣诞这一期的状态。
  • 被挂起时：选了展示公告的照常显示，没选的不显示（挂起功能上线后才生效）。
  • 查不到状态时这次先不显示。
公式
显示按钮 ＝ 圣诞这一期处于 {预热中, 进行中, 领奖期} 且 状态查得到（挂起时还要选了展示公告）
涉及端
H5iOSFlutter 安卓

F01-03点击离开游戏并跳转落地页查看 PRD ›

要做什么
  • 退出游戏的方式和 Home 一样，失败或断网时也一样。
  • 只进圣诞这一期的落地页（运营上线前给活动编号）。
公式
无

  • PC、老版本 App、安卓原生老包不显示。

F02-01入口曝光与点击查看 PRD ›

要做什么
  • 打开侧栏看到按钮记 1 次曝光；点按钮记 1 次点击。
  • 只记次数，不算人数。
  • 记录失败不影响跳转。
