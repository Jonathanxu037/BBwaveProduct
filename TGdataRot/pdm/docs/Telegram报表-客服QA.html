Telegram报表 · 客服 QA（内部答疑）

版本：v1.2适用：运营、客服回答内部同事的问题依据：PRD、后台操作手册

适用范围

内部人员使用的 Telegram 报表机器人「BBWave报表助手」，人员与机器人私聊使用，配置在两站后台【系统管理 › Telegram报表配置】。玩家用不了，本页只写内部同事的问题和答疑口径。

这次改了什么

已在后台登记的同事打开机器人私聊点「开始」后，可按范围（789BINGO、789GAMES、全网数据）查看各渠道和代理线的今日、昨日、前日数据及较昨日同时段对比。报表是图片，只发到本人私聊，发出满 24 小时自动删除，不能转发、保存。

回答前的核查步骤

  1. 人员权限：【人员配置】按 Telegram ID 查是否存在、是否启用、勾了哪些渠道和「代理线查询」；两站分别查，ID 要一致。
  2. 渠道状态：【渠道配置】看该渠道和父级「菜单显示」是否开启，是否标红「范围重叠」「无可用代理」。
  3. 机器人状态：【机器人管理】看总停用开关、当前服务机器人和私聊链接、状态和「未删除 N 份」。

问答

1同事问：机器人说我没有报表查看权限，或没有可查看的渠道？

答疑口径
机器人只给后台登记并启用的人员用。请把回复里的 Telegram ID 手动抄写发给运营登记（这条回复不能转发），看两站要用同一 ID。同一 ID 10 分钟内只回复 1 次，没再收到回复属正常，不用反复发。「没有可查看的渠道」是你勾的渠道已删除、隐藏或无可用代理（全网数据下也可能两站勾的渠道没有相同的），需运营调整。
回答前查什么
核查步骤 1、2。
找谁处理
运营；配置都正确仍提示无权限时转技术。

2同事问：我看不到「全网数据」，或只看到一个子站？

答疑口径
在哪个子站登记并启用就显示哪个；两站都登记并启用同一 ID 才有「全网数据」。
回答前查什么
两站是否都有这个 ID 且启用。
找谁处理
运营。

3同事问：菜单里某个渠道按钮不见了，或点了提示「该渠道已不可用」？

答疑口径
按钮按当前权限和配置显示。后台改过配置后，你下次操作时机器人按新权限处理；点到已不可用的渠道会收到新首页菜单并提示「该渠道已不可用，请在新菜单里选择」，在新菜单里重新选即可。全网数据下的渠道要两站都有同名渠道、父级相同、都为你勾选。
回答前查什么
核查步骤 1、2；全网数据下另一站有没有同名渠道。
找谁处理
运营。

4同事问：报表怎么不见了？

答疑口径
报表发出满 24 小时自动删除。重新查询即可。
回答前查什么
不用核查。
找谁处理
不需要转交。

5同事问：报表过了删除时间还在？

答疑口径
删除失败会自动重试，排队时实际删除可能晚几分钟；发出满 48 小时仍未删除时机器人无法再删，请在私聊里手动删除该报表。屏蔽了机器人的，请解除屏蔽后手动删除。
回答前查什么
核查步骤 3：发出它的机器人是否有「未删除 N 份」、是否疑似封禁或 Token 失效。
找谁处理
本人手动删除；后台管理员通知后在【机器人管理】清除标记；机器人疑似封禁或 Token 失效时转技术。

6同事问：机器人说「报表服务暂停中」或「报表机器人暂不可用，正在更换」？

答疑口径
「暂停中」是该子站总停用开关已打开；「暂不可用」是该子站的服务机器人被手动停用、暂时没有可接替的机器人。这个子站和全网数据的渠道报表暂时不能查；全网代理线查询只查另一站，结果注明「某子站 暂停中」。另一站照常，请稍后再试。
回答前查什么
核查步骤 3：「暂停中」看总停用开关；「暂不可用」看服务机器人是否被手动停用、有没有可接替的机器人。
找谁处理
运营；没有可接替的机器人时同时转技术。

7同事问：机器人的数据和后台平台报表对不上？

答疑口径
今日是实时数据，平台报表每 30 分钟统计一次，会有差异。昨日、前日应一致：子站下对该站对应时区的日报表（789Bingo 为 UTC+8，789Games 由技术按平台时区确定），全网数据下对两站合计；金额四舍五入到个位比较；不计测试用户。
回答前查什么
对方比的是哪个子站、哪一天、哪一种日报表。
找谁处理
按口径仍不一致时转技术。

8同事问：昨日的数据和之前看到的不一样？

答疑口径
任何日期都按查询时的绑定和用户当前所属代理统计。调整过绑定，或做过会员变更代理、直属会员转移、投注站用户转移，历史日数据会变；变更代理还会改变测试标识，全站和全网数据也会变。
回答前查什么
近期是否改过渠道配置或做过转移操作。
找谁处理
运营确认；没调整过仍有变化时转技术。

9同事问：代理线查询搜不到代理，或报表写「仅含你可查看的渠道」「全网数据（只含某子站）」？

答疑口径
只查你有代理线查询权限的子站；没有该站「全站」权限时只搜和统计你可查看渠道内的代理和用户。全网数据下有一个子站可查就出报表，并注明只含哪个子站和原因。只搜到 1 个代理时直接出报表；没搜到时直接回复新账号即可重新搜索。需要更大范围请运营调整权限。
回答前查什么
核查步骤 1：两站是否勾了「代理线查询」「全站」，代理所在渠道是否在可查看渠道内。
找谁处理
运营。

10同事问：机器人提示「报表机器人已更换，请打开 @用户名 并点「开始」」或「报表生成中，请稍候」？

答疑口径
「已更换」是更换通知，表示服务机器人换了，请点消息里的「打开 @用户名」或打开运营发的私聊链接（以后台机器人管理页显示的链接为准），进入新机器人私聊点「开始」，旧机器人不再处理查询。更换通知发出满 24 小时自动删除。「报表生成中」表示你已有一份报表在生成，发出后再查。
回答前查什么
不用核查。
找谁处理
不需要转交。

11同事问：怎么开始用机器人？打开后没有菜单？

答疑口径
按这个顺序开通：① 打开运营发的机器人私聊链接（t.me/用户名），点「开始」；② 机器人回复你的 Telegram ID，这条回复不能转发，请手动抄写发给运营；③ 运营登记后，发 /menu 即收到首页菜单。机器人只在你操作后回复，除更换通知外不主动发消息；屏蔽过机器人的要先解除屏蔽。报表机器人永远不会要求输入后台账号、密码或验证码。
回答前查什么
核查步骤 1；核查步骤 3 的当前服务机器人，确认对方打开的是它。
找谁处理
运营；已登记、已点「开始」仍无任何回复时转技术（可能是服务机器人疑似封禁或 Token 失效）。

12客服同事问：玩家说找到了「BBWave报表助手」或收到它的中文回复，怎么答？

答疑口径
这是公司内部工具，不是客服，请通过站内在线客服或官方 Telegram 客服联系（英文话术按现有口径翻译）。
回答前查什么
不用核查。
找谁处理
不需要转交；玩家反映有人冒充该机器人索要账号、密码时转运营。
