Telegram报表 · 需求要点 · v1.0

版本：v1.0端：Telegram 机器人、789Bingo 后台、789Games 后台依据：需求开发 PRD 文档

一句话需求

新建一个 Telegram 报表机器人，在授权的 Telegram 群内使用：群成员通过输入框左侧「菜单」按钮和输入框下方的报表键盘，选择全站 / cicc / 短信 / 网红 / 谷歌 / oem 渠道，或输入代理账号，在一张表格里按列查看 789Bingo、789Games 和全站（两站合计）12 项指标的今日实时数据与昨日全天对比；报表发出满 1 小时或生成新报表时自动删除。两站管理后台【系统管理 › Telegram报表配置】新增渠道配置和授权群。

业务流程

1
打开报表键盘：在授权群里点「菜单」选 /menu 或直接发 /menu → 校验本群权限
↓
2
按钮矩阵：打开授权群即显示，不用先发命令
↓
3
选查询对象：点渠道，或发送代理账号
↓
4
出报表：删除本聊天旧报表 → 发出新报表
↓
5
自动删除：发出满 1 小时删除
A - 授权群

发出菜单群内全员可用；报表只显示有权限站点的列

B - 未授权群 / 私聊

不返回数据未授权群附群 ID；私聊引导到群里使用

C - 代理账号不存在

回复未找到不生成报表、不删旧报表

开发功能点

F01-01菜单按钮与命令查看 PRD ›

要做什么
  • 输入框左侧蓝色「菜单」列出 /menu、/agent。
  • /menu 在输入框下方打开报表键盘；其他命令回复不支持。
公式
无
涉及端
Telegram 机器人

F01-02报表菜单查看 PRD ›

要做什么
  • 输入框下方 3 列按钮矩阵：6 个渠道、代理线查询；不设站点按钮和留存周期按钮。
  • 打开授权群即显示，所有成员可用；点按钮等于发出按钮文字，点渠道立即出报表。
  • 「⌨」可收起，/menu 重新显示。
公式
默认周期 = 7 天
涉及端
Telegram 机器人

F01-03授权校验查看 PRD ›

要做什么
  • 每次操作都按群、按站点校验授权群名单。
  • 未授权群回复未开通和群 ID；私聊回复只在授权群内使用；群里普通消息不回应。
公式
群可看站点 S ＝ 群 ID ∈ S 后台授权群名单 且 状态为启用；私聊 → 不返回数据
涉及端
Telegram 机器人后端

F02-01报表生成与展示查看 PRD ›

要做什么
  • 先发「正在生成报表…」，再发报表：标题、截至时间、指标表、自动删除时间。
  • 表格列：789Bingo | 789Games | 全站（两站合计）；每格大字今日（带 ▲▼）、小字昨日和变化百分比。只授权一站时只显示该站一列。
  • 报表下方不带按钮，不提供刷新；再点一次渠道按钮即生成新报表。
  • 生成中重复点击只提示；30 秒未生成回复失败和重试。
  • 渠道在本群有权限的站点都未绑定代理时，不显示该渠道按钮；只在一站绑定时报表只显示该站一列。
公式
今日 > 昨日 → ▲ 绿色；今日 < 昨日 → ▼ 红色；相等或任一为 - → 无箭头
变化百分比 ＝（今日 − 昨日）÷ |昨日| × 100%，1 位小数；昨日为 0 或任一为 - → -；留存显示百分点差（pp）
全站列：人数、金额 ＝ 两站相加；人均、留存 ＝ 两站合计分子 ÷ 合计分母
涉及端
Telegram 机器人后端

F02-02指标口径查看 PRD ›

要做什么
  • 今日 = 00:00 至生成时刻实时；昨日 = 全天；GMT+8。
  • 12 项指标沿用平台报表口径；渠道用户按所属代理归属（就近）。
公式
存提差 ＝ 存款额 − 提款金额
人均首存 ＝ 首存金额 ÷ 首存人数；人均存款 ＝ 存款额 ÷ 存款人数（分母 0 显示 -）
GGR ＝ 总投注 − 总派彩
次日留存：今日 ＝ 昨天注册用户今天截至生成时刻有登录人数 ÷ 昨天注册人数；昨日 ＝ 前天注册用户昨天有登录人数 ÷ 前天注册人数
7日留存：今日 ＝ 7 天前注册用户今天截至生成时刻有登录人数 ÷ 该日注册人数；昨日 ＝ 8 天前注册用户昨天有登录人数 ÷ 该日注册人数
涉及端
后端

F03-01代理线查询查看 PRD ›

要做什么
  • 点「代理线查询」→ 机器人 @ 点击人要求回复，点击人输入框自动进入回复状态，直接输入账号；或发「/agent 账号」。
  • 同时查有权限的两站，账号存在的站点各一列，两站都有时加全站列；范围为该代理及全部下级的用户。
  • 有权限的站点都没有这个账号时回复未找到，不删旧报表。
公式
范围 ＝ 代理本身 ∪ 全部下级代理名下的用户；账号去首尾空格、不区分大小写
涉及端
Telegram 机器人后端

F04-01发出 1 小时自动删除查看 PRD ›

要做什么
  • 报表发出满 1 小时删除；服务中断恢复后立即补删。
  • 消息已不存在或机器人已被移出时跳过，不提示。
公式
删除时间 ＝ 发出时间 + 1 小时
涉及端
Telegram 机器人

F04-02新报表替换旧报表查看 PRD ›

要做什么
  • 同一聊天发出新报表时，立即删除之前的报表和失败提示（不论是谁查的）。
  • 不同聊天互不影响。
公式
无
涉及端
Telegram 机器人

F05-01渠道配置查看 PRD ›

要做什么
  • 5 个固定渠道，各绑定多个代理。
  • 同站点一个代理只能绑一个渠道；保存后下一份报表生效。
公式
用户所属渠道 ＝ 代理链上离用户最近的已绑定代理所在渠道
涉及端
两站后台前端后端

F05-02授权群查看 PRD ›

要做什么
  • 增、改（群名称和状态）、删、启停，筛选和分页。
  • 保存立即生效；已发出报表仍按 1 小时删除。
公式
群 ID 以 -100 开头；同站点不重复；群名称 1–30 字
