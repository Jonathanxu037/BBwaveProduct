规则批注

  1. 渠道归属：用户按当前所属代理归入渠道；绑定代理及其全部下级代理的用户都算该渠道；代理链上命中多个已绑定代理时，按离用户最近的一个归属。PRD 规则 N6 · F05-01 渠道配置
  2. 一个代理只能绑定一个渠道：添加已绑定到其他渠道的代理时，提示「代理 xx 已绑定到渠道「cicc」，同一代理只能绑定一个渠道」；输入不存在的账号提示「代理账号不存在」；同一渠道重复添加提示「该代理已添加」。PRD 规则 N7 · F05-01
  3. 生效时间：保存后，机器人下一次生成的报表按新配置统计；已发出的报表不变。PRD 规则 N8 · F05-01
  4. 未绑定代理：代理数为 0 的渠道，在只看本站的群里不显示按钮；两站汇总群里两站都为 0 才不显示，只有一站绑定时报表只显示该站一列。保存后机器人在相关群里重新发菜单。PRD 规则 N9 · F01-02
  5. 操作日志：保存记入后台现有操作日志，沿用现有。PRD 5.1 渠道配置
