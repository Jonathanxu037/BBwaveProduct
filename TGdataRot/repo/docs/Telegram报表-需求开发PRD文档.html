    2.2 权限分支（按人员）

    A - 已登记并启用

    C - 在非服务机器人私聊（含原服务机器人）

    回复更换通知提示打开当前服务机器人并点「开始」（没有服务机器人，或服务机器人疑似封禁、Token 失效时不回应；N67）

    2.3 查询对象分支

    A - 点渠道按钮

    渠道报表有子渠道的父级进入下一级菜单

    B - 代理线查询

    模糊搜索搜到 1 个直接生成报表；2–10 个列按钮点选（含下级）

    C - 没有搜到

    回复未找到输入框自动进入回复状态，直接输入新账号

    2.4 子站可用性分支（按所选子站）

    A - 正常

    照常生成有可用机器人且总停用开关关闭

    B - 总停用开关打开

    C - 没有可用机器人

    按原因回复或停止原机器人手动停用时回复「暂不可用」提示，影响范围同 B（N55）；原机器人疑似封禁或 Token 失效时，全部子站和全网数据停止出报表，人员收不到回复（N52）；有机器人可接替或原机器人恢复后自动恢复出报表（N52）

    列表 F05-01列：位置、渠道名称、父级渠道、绑定代理、菜单显示、最后修改（GMT+8）、操作。默认渠道「全站」「自然流量」固定在最上，标「默认」，只能「查看」；其余按创建时间，子渠道在父级后。上方显示「自建 N 个，最多 20 个」。绑定代理列：整枝勾选只显示最上层代理，部分勾选显示勾上的下级。所绑代理全部被删除或停用：名称旁标红「无可用代理」，绑定代理列标红「已全部删除或停用」，悬停提示点「编辑」重新绑定；菜单不显示（N9），重新绑定后标记消失。
    新建渠道名称、父级、绑定代理必填；自建渠道满 20 个（含子渠道）时按钮置灰。保存后排在同级最后，默认在菜单显示，加入人员配置选项（勾选按 5.1），不主动推送，提示「已新建渠道「名称」，菜单里已显示该按钮」（子渠道加「；已全选父级「父级」的人员自动勾选该子渠道」）。

    父级渠道下拉树：第一项为当前子站（默认），其下缩进列出本站全部自建渠道。选子站即顶层渠道，选渠道即其子渠道。编辑时本渠道及下级置灰；改父级时下级随之移动，已勾代理清空重选。
    绑定代理本站大代理（含投注站，按大代理处理）和代理的树，默认折叠，只显示首级（父级是子站时为大代理，父级是渠道时为该渠道的代理），「▸」逐级展开，显示下级个数；可搜索，命中路径展开。勾上级 = 下级全勾，取消上级 = 下级全取消，取消某下级上级半选；整枝勾选只存最上层代理（以后新增的下级自动包含），部分勾选存勾上的下级。投注站名下挂有其他大代理时，整枝勾选即包含它们及全部下级（3.9）。父级是子站时，已属其他顶层渠道的代理置灰，旁写「已属于渠道「名称」」。未选提示「请至少选择一个代理」。
    保存校验（N7）「代理 xx 已在顶层渠道「yy」的范围内，不能再绑定到「zz」」；「代理 xx 的下级 ww 已在顶层渠道「yy」的范围内，不能再绑定到「zz」」；「代理 xx 不在父级渠道「yy」的范围内，不能绑定到「zz」」。都不能保存，绕过页面提交同样拦截。
    编辑可改名称、父级、代理。父级去掉某代理时，子渠道里属于它的部分一起去掉；子渠道因此没有代理时不能保存，提示先调整子渠道。保存后提示「保存成功，下次生成的报表按新配置统计」（N8）。改名且其他子站有原名称同名渠道时，输入框下方显示「改名后，全网数据下的「原名称」按钮将不再显示，直到各子站名称一致」，点保存直接保存（N45）。
    「范围重叠」标记（N44）冲突的顶层渠道名称旁标红，悬停或点击显示重叠代理、它进入两个渠道的时间和统计归属；编辑时该代理标红「与顶层渠道「xx」范围重叠，取消勾选后可保存」。
    菜单显示只有自建渠道有开关，默认渠道显示「始终显示」。点击立即生效，提示「已在菜单隐藏「名称」」（有子渠道加「，其子渠道一起隐藏」）或「已在菜单显示「名称」」；人员勾选保留，重新打开后按钮回原位。父级已隐藏时子渠道开关置灰，显示「随父级隐藏」；联动和统计按 N64。
    删除确认后删除，菜单里的按钮和人员勾选一并去掉，提示「已删除渠道「名称」」，不可恢复；已发出的报表不变。有子渠道时提示「请先删除或改挂它的子渠道」。
    查看默认渠道只读显示类型、父级（子站）、查询范围（N6）；不可改、不可删，不计入上限。

    测试连接只校验 Token：「连接正常：@实际用户名」或「Token 无效，请检查后重试」；为空「请先填写 Token」（编辑时测已保存的）；不发消息、不保存。
    启用 / 停用立即切换，提示「已停用，不再调取本子站数据」或「已启用，恢复调取本子站数据」；疑似封禁、Token 失效时不显示。停用服务机器人时按 N52、N55、N67，提示同时写明切换结果。
    「未删除 N 份」标签橙色标签（N28），只统计该机器人发出、满 48 小时仍未删除的报表。悬停显示份数和最早发出时间（GMT+8）；点击弹窗显示份数、最早发出时间和涉及人员（昵称、Telegram ID），由后台管理员通知这些人员在私聊里手动删除，通知后点「已通知，清除标记」，标签消失，提示「已清除未删除标记」。清除标记不会删除报表。
    疑似封禁处理「处理」弹窗列出步骤（停止发送 → 核查整改 → 申诉 → 技术核查后恢复）和错误记录；它是服务机器人时已按 N52 切换，由后台管理员转告新机器人私聊链接（N67）。「生成故障材料」：机器人用户名、发生时间、官方提示、近 7 天发送量、错误记录、整改记录，不含 Token、人员信息、报表数据。「确认已恢复」只能人工点（技术核查可用后），全部子站恢复为之前状态，按技术配置的速度逐步恢复发送。
    删除以下情况点「删除」直接弹「不能删除」提示，只有「知道了」；同时满足多种时，在同一个提示里按下面顺序每种一行，全部列出：① 标「服务中」——「这个机器人正在服务，请联系技术更换后再操作。」；② 原服务机器人更换未满 7 天（N67）——「更换未满 7 天，MM-DD HH:mm（GMT+8）后可删除。」（时间 = 更换时刻 + 7 天）；③ 它发出的报表还有未到删除时间或正在重试的——「这个机器人还有 N 份报表等待自动删除，最晚 MM-DD HH:mm（GMT+8）删除完，之后再删除机器人。」（最晚 = 最后一份报表的删除时间，即发出 + 24 小时；到时仍在重试的，满 48 小时后转为「未删除 N 份」）；④ 有「未删除 N 份」标记——「请先处理「未删除 N 份」，再删除。」。例：原服务机器人刚换下且还有 3 份报表待删除时，提示两行「更换未满 7 天，11-18 14:32（GMT+8）后可删除。」「这个机器人还有 3 份报表等待自动删除，最晚 11-12 14:32（GMT+8）删除完，之后再删除机器人。」其余机器人：确认框「删除后，机器人「名称」（@用户名）在全部子站停止使用。确定删除？」，确认后提示「删除成功」，其他子站同步（N53）。
    Token 安全Token 保存后，后台页面和接口都只返回后 4 位，任何账号（含有机器人管理权限的账号）都不能再看到完整 Token；技术配置的初始服务机器人同样。列表、弹窗、日志、故障材料都只显示后 4 位。泄露时先在 Telegram 作废，再填新 Token。
    操作日志添加、编辑、更换 Token、启停、删除、总停用开关、确认已恢复、生成故障材料、清除未删除标记都记日志（N56）。系统自动动作也记日志，操作人写 SYSTEM，详情写原因和切换前后的机器人：自动停用（疑似封禁、Token 失效）、自动切换服务机器人、确认已恢复后的状态恢复。跨子站同步的改动按 N53 记入其他子站日志。
