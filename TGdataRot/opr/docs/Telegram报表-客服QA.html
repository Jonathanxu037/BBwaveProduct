版本 / Version：v1.0适用 / For：客服 Customer Service依据 / Based on：PRD、后台操作手册 Admin Manual

适用范围 Scope

789Bingo、789Games 内部人员使用的 Telegram 报表机器人。玩家看不到、也用不了这个机器人；本 QA 用于回答内部同事的问题。
The Telegram report bot for internal staff of 789Bingo and 789Games. Players cannot see or use it; this Q&A is for answering colleagues.

这次改了什么 What changed

授权人员可在 Telegram 里查看两站各渠道（全站、cicc、短信、网红、谷歌、oem）和指定代理线的今日实时数据与昨日对比。报表发出满 1 小时、或同一聊天再查一次时自动删除。对玩家没有任何变化。
Authorized staff can view today's real-time data vs. yesterday for each channel (All, cicc, SMS, Influencer, Google, OEM) and for a given agent line, on both sites, in Telegram. Reports are deleted 1 hour after being sent, or when a new report is generated in the same chat. Nothing changes for players.

客服核查步骤 How to check

  1. 是否有权限：后台【系统管理 › Telegram报表配置 › 授权群】按群 ID 查询，看是否存在且为「启用」。两站分别查。
    Access: In admin 系统管理 › Telegram报表配置 › 授权名单 (System › Telegram Report Settings › Access List), search the Telegram ID and check it exists and is enabled. Check each site separately.
  2. 渠道按钮不见了：同一菜单的「渠道配置」标签，看该渠道的代理数是否为 0（为 0 时不显示按钮）。
    Channel button missing: On the 渠道配置 (Channel Settings) tab, check whether the channel has 0 agents (the button is hidden when it has none).

问答 Q&A

1玩家问：你们的 Telegram 机器人能查数据吗？Player: Can your Telegram bot show data?

回复玩家Reply
This bot is for internal use only and is not available to players. For your account details, please check the Account page in the app or contact us here.
该机器人仅供内部使用，玩家无法使用。账户信息请在 App 的 Account 页面查看，或在这里联系我们。
客服核查Check
不用核查；不要向玩家透露机器人名称和报表内容。
No check needed. Do not share the bot name or any report content with players.
转交Escalate
玩家声称看到了报表内容时，截图转运营负责人。
If a player claims to have seen report content, send screenshots to the Operations lead.

2同事问：机器人说我没有权限？Colleague: The bot says I have no access?

回复同事Reply
The bot only works in authorized groups. Please use it in the authorized operations group. If you need a new group enabled, send the group ID shown in the bot's reply to Operations.
机器人只在授权群里使用，请到已授权的运营群里查看；需要开通新群时，把机器人回复的群 ID 发给运营。
客服核查Check
按「客服核查步骤」查授权群。
Check the access list as described in "How to check".
转交Escalate
已在名单中且启用仍提示无权限时，转技术。
If the ID is listed and enabled but access is still denied, escalate to Tech.

3同事问：报表怎么不见了？Colleague: Where did the report go?

回复同事Reply
Reports are deleted automatically 1 hour after being sent, or when someone in the same chat generates a new one. Just tap a channel again to get the latest report.
报表发出满 1 小时会自动删除；同一聊天里有人再查一次，上一份也会被删除。重新点渠道即可看到最新报表。
客服核查Check
不用核查。
No check needed.
转交Escalate
不需要转交。
No escalation needed.
