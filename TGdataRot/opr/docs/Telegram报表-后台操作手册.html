Telegram报表 · 人员、渠道与机器人配置操作手册

写给运营：在两站后台【系统管理 › Telegram报表配置】配置人员、渠道和机器人；人员和渠道两站各配各的，机器人信息两站同步。

重要结论
  • 人员在 Telegram 和服务机器人私聊使用，菜单、查询和报表只在本人私聊收发，其他人看不到；初始服务机器人和发送限制由技术配置（PRD「3.2 子站与人员」）。
  • 两站登记同一 Telegram ID 并都启用，才能看「全网数据」（PRD「3.2 子站与人员」）。
  • 报表发出满 24 小时自动删除；生成新报表不删除之前的报表（PRD「3.7 生成、发送与删除」）。
  • 满 48 小时仍未删除的报表机器人无法再删，后台标「未删除 N 份」，需通知人员手动删除（PRD「3.7 生成、发送与删除」）。
  • 开通人员要先发私聊链接、人员点「开始」拿到 Telegram ID，再登记（PRD「3.2 子站与人员」N68）。
  • 各子站按自己平台的时区统计：789Bingo 为 UTC+8，789Games 由技术按平台时区确定；全网数据为两站相加（PRD「3.5 统计时段、指标口径与报表格式」）。本需求三个页面的时间均为 GMT+8。
  • 同一子站内一个代理（含下级）只属于一个顶层渠道（PRD「3.4 渠道与统计范围」）。

整体操作流程

1
上线前：运营在 Telegram 创建专用机器人（名称「BBWave报表助手」，用户名不含 789、bingo、support、cs、service 等玩家会搜索的词），交技术接入；技术设置头像和简介，指定初始服务机器人。
2
超级管理员（有「机器人管理」权限的账号）在【机器人管理】登记机器人（另一子站同步）并分配后台权限；确认「正常」，在另一子站启用它（另一站初始为「停用」）。
3
【渠道配置】新建渠道、设父级、绑定代理，按「一个代理只属于一个顶层渠道」核对。
4
开通人员（N68）：把【机器人管理】顶部的私聊链接（t.me/用户名）发给同事；同事打开后点「开始」，收到带本人 Telegram ID 的回复，手动抄写 ID 发给你（这条回复不能转发）。
5
有「编辑人员配置」权限的运营在【人员配置】登记这个 ID 并勾选渠道；看两站的，两站都登记同一 ID。
6
请同事发 /menu，确认能看到按钮并生成报表。

01渠道配置

这个功能做什么

一个渠道就是菜单里一个按钮，数据 = 所绑代理及其全部下级名下用户。默认渠道「全站」= 本站全部；「自然流量」= 全站 − 各顶层渠道合计。

菜单路径与权限

系统管理 › Telegram报表配置 › 渠道配置。查看需「查看」权限，新建、编辑、删除需「编辑渠道配置」权限（见「04 后台通用」）。

字段说明

字段含义默认值
渠道名称即按钮文字（「📊 渠道名称」）。必填，1–10 个字符（各类字符算 1 个，去掉首尾空格后计），不能重名（不区分大小写），不能用「全站」「自然流量」「全网数据」或子站名称。-
父级渠道默认当前子站；选已有渠道则为其子渠道，只能从其绑定代理里选。层级不限。当前子站
绑定代理代理上下级树，默认只显示首级；勾上级即勾上全部下级。投注站按大代理勾选，名下挂有其他大代理时整枝勾选即包含它们及全部下级。必填。-
菜单显示只有自建渠道有：关闭后菜单里对所有人隐藏，人员勾选保留。「全站」「自然流量」始终显示。开启

操作步骤

1
点「+ 新建渠道」，填名称。
2
选父级：顶层渠道选子站，子渠道选父级渠道。
3
勾选代理（可搜索），保存。
4
暂不显示：关闭「菜单显示」；删除：先删除或改挂子渠道，再删除。

生效时间

保存后立即生效，不主动推送；人员下次发消息或点按钮时按新配置处理，点到已不可用的渠道会收到新首页菜单（PRD N61）。查询任何日期都按查询时的绑定关系统计；已发出的报表不变。

注意事项

  • 自建渠道最多 20 个（含子渠道），满了「新建渠道」置灰；默认渠道不能改、删。
  • 提示代理「已在顶层渠道「××」的范围内」：先到那个渠道取消它，或换一个代理。
  • 红色「范围重叠」：有代理换了上级，同时落在两个顶层渠道；统计按它先进入的渠道算（换上级不改归属），请取消重叠的代理。
  • 新建顶层渠道后，已登记人员要到【人员配置】勾选；新建子渠道时，已全选父级的人员自动勾上。
  • 关闭父级「菜单显示」，子渠道一起隐藏，不影响统计。
  • 红色「无可用代理」：所绑代理全部被删除或停用，菜单已不显示，请点「编辑」重新绑定。
  • 改名时若另一子站有同名渠道，输入框下方会提示：保存后全网数据下该渠道消失，直到两站名称一致。
  • 会员变更代理、直属会员转移、投注站用户转移后，用户随新代理计入新渠道；变更代理还会改变测试标识。全站、全网和各渠道的历史日数据都会变。
  • ※ 删除渠道不能恢复；配错会让渠道数据失真，保存前对照代理清单核对。

02人员配置

这个功能做什么

登记能查本子站报表的人员和渠道。本站登记并启用才显示本站按钮；两站都登记并启用同一 ID 才有「全网数据」。

菜单路径与权限

系统管理 › Telegram报表配置 › 人员配置。查看需「查看」权限，添加、编辑、启停、删除需「编辑人员配置」权限。

字段说明

字段含义默认值
Telegram ID人员的 Telegram 数字 ID（正整数），编辑时不可改。人员打开机器人私聊点「开始」后，机器人回复带其 ID 的未开通回复，由人员手动抄写发给你。-
Telegram 昵称登记后，人员下次私聊机器人时按 Telegram ID 自动获取，不可修改；还没获取到时显示「待获取」。-
可查看渠道本站可查的渠道和代理线查询；至少勾一个渠道（代理线查询不算）。不勾选
状态启用：可查询；停用：立即不能查询，记录保留。启用

操作步骤

1
点「+ 添加人员」，填同事抄写发来的 Telegram ID（见「整体操作流程」第 4 步）。
2
勾选可查看渠道（勾父级即勾全部子渠道；只勾部分子渠道时看不到「父级·全渠道」）。
3
保存。临时取消用状态开关；不再需要时删除。

生效时间

立即生效，不主动推送；排队中的报表发出前会再校验；已发出的收不回，按原定时间删除。

注意事项

  • 两站 ID 不一致会被当作两个人。
  • 没勾「代理线查询」时菜单里没有该按钮。
  • 停用或删除后他立即不能查本站报表；他已收到的报表按原定时间（发出满 24 小时）删除。
  • 所勾渠道全部被删除、隐藏或无可用代理时记录保留，他操作时会提示没有可查看的渠道（有代理线查询权限时只显示该按钮）；渠道被删光时列表标红「无可查看渠道」，请重新勾选。
  • 人员离职或换岗当天，在各子站停用或删除；发现账号被盗立即停用。

03机器人管理

这个功能做什么

登记机器人、看实时状态、用总停用开关让本站停止出报表、处理疑似封禁和未删除的报表。同一时间只有一个服务机器人（初始由技术指定），标「服务中」，页面顶部显示它的私聊链接。

菜单路径与权限

系统管理 › Telegram报表配置 › 机器人管理。查看需「查看」权限；其他操作需「机器人管理」权限，上线时只给超级管理员。

字段说明

字段含义默认值
机器人名称便于识别，必填，1–30 个字符（去掉首尾空格后计）。-
用户名Telegram 用户名，以 bot 结尾，如 bbwave_report_a_bot，不加 @，不能重复。须与 Token 对应的机器人一致，否则提示「用户名与 Token 不匹配」，不能保存。-
Token创建机器人时得到的访问凭证，不能重复。保存后页面和接口都只返回后 4 位，任何账号都看不到完整 Token；编辑时留空不修改；泄露时先在 Telegram 作废再填新的。-
状态正常：可发送；限流中：到时自动恢复；停用：本站人工停用；停用（疑似封禁）、停用（Token 失效）：两站自动停用，需人工处理。「服务中」：当前服务机器人。另一站里新添加的机器人初始为「停用」。正常
未删除 N 份该机器人发出的报表满 48 小时仍未删除，机器人已无法删除（只计报表）。点开看涉及人员，通知他们在私聊里手动删除后点「已通知，清除标记」。-
当前服务机器人和私聊链接页面顶部显示服务机器人和 t.me/用户名，可复制，发给人员打开后点「开始」。-

操作步骤

1
点「+ 添加机器人」，填名称、用户名、Token，「测试连接」显示「连接正常：@实际用户名」、核对与填写的用户名一致后保存；需要它服务另一站时，到另一站启用。
2
暂停本站：打开顶部总停用开关并确认；恢复时关闭并确认。
3
「停用（疑似封禁）」：点「处理」按步骤核查、整改、申诉，可生成故障材料；技术核查可用后点「确认已恢复」。
4
「停用（Token 失效）」：编辑填新 Token。
5
橙色「未删除 N 份」：点开，通知列出的人员手动删除，再点「已通知，清除标记」。

生效时间

启停和总停用开关立即生效，只作用于本站；总停用开关打开后排队中的本站报表取消，关闭后不补发。添加、改名、换 Token、删除另一站同步。

注意事项

  • ※ 总停用开关打开后，本站和「全网数据」都不出报表，人员收到「报表服务暂停中，请稍后再试。」；另一站照常，全网代理线查询只查另一站。
  • 服务机器人在任一站停用（含自动）时，切换到可接替的机器人：两站都启用，正常的优先、限流中的其次，「服务中」和顶部私聊链接随之更换；切换时已在生成、排队的报表由原机器人发完。已切换到其他机器人后，原机器人恢复不自动切回。
  • ※ 没有可接替的机器人时：原机器人只是手动停用的，被停用的站和全网数据回复「报表机器人暂不可用，正在更换，请稍后再试。」，另一站仍由原机器人服务；原机器人疑似封禁或 Token 失效的，两站和全网数据都停止出报表，人员私聊收不到任何回复，页面红字提示并告警。请尽快添加机器人并在两站都启用，或恢复原机器人（被停用的站重新启用、疑似封禁的「确认已恢复」、Token 失效的更换 Token）：有机器人可接替时系统自动切换到它并通知人员；原机器人先恢复的仍由它服务，直接恢复出报表；红字随即消失（PRD N52）。
  • ※ 更换服务机器人后，人员须打开新机器人私聊并点「开始」才能使用。原机器人能发消息时会私聊通知点过它「开始」的人员（更换通知，发出满 24 小时删除）；人员在原机器人或备用机器人私聊发消息，也会收到更换通知。原机器人疑似封禁或 Token 失效时发不出通知，页面顶部会提示，请把新机器人私聊链接转告全部已登记人员，并请人员回复确认已能收到菜单。
  • 不能删除：标「服务中」的（提示联系技术更换）、原服务机器人更换未满 7 天的（提示可删除的时间，GMT+8）、还有报表等待自动删除的（提示最晚删除完的时间，GMT+8）、有「未删除 N 份」标记的（先处理标记）。同时有几种原因时，提示里会全部列出，处理完再删除。
  • 机器人停用或更换后，仍由它按时删除自己发出的报表。
  • 更换 Token 后旧 Token 立即停用；已泄露的请在 Telegram 作废。
  • 疑似封禁、Token 失效、更换机器人需转告人员、报表满 48 小时未删除、连续限流时，后台顶部出现「Telegram报表告警」，点击进入本页。

04后台通用

  • 权限分四项：查看、编辑人员配置、编辑渠道配置、机器人管理；各项操作记日志，Token 只记后 4 位。系统自动停用、自动切换服务机器人、确认已恢复后的状态恢复也记日志，操作人为 SYSTEM；在一站改机器人，另一站日志注明「由 子站 同步」。
  • 本需求三个页面的时间均为 GMT+8；操作日志沿用现有显示时区（789Bingo 为 −04:00），两者可能相差 12 小时。
  • 人员列表按添加时间倒序，每页 20 条（可选 10 / 50 / 100），查询后回第 1 页，无结果显示「暂无数据」。渠道、机器人列表不分页；机器人按正常、限流中在前，停用在后，同组按添加时间。
  • 人员、渠道各站一份；机器人名称、用户名、Token 两站共用并同步；启停和总停用开关各站分别管理。
  • 全网数据下渠道按名称合并，只显示两站都有、父级相同、都勾选的，层级和顺序以 789Bingo 为准。

常见问题

同事说机器人回复「你还没有报表查看权限」？
请他把回复里的 Telegram ID 手动抄写发给你（回复不能转发），到【人员配置】登记并启用；看两站的，两站都登记同一 ID。同一 ID 10 分钟内只回复 1 次，没收到新回复属正常。
同事找不到机器人或点了没反应？
把【机器人管理】顶部的私聊链接发给他（以这个链接为准），打开后点「开始」；屏蔽过机器人的要先解除屏蔽。
人员列表昵称显示「待获取」？
登记后他还没再私聊过机器人；他下次私聊时自动获取，不影响使用。
同事看不到「全网数据」？
只在一站登记、两站 ID 不一致，或其中一站已停用。
菜单里某个渠道按钮不见了？
查：是否勾选；该渠道和父级「菜单显示」是否开启；是否标红「无可用代理」；全网数据下还要两站都有、父级相同且都勾选。
人员收到「报表机器人暂不可用，正在更换，请稍后再试。」？
本站服务机器人被手动停用，又没有可接替的机器人。到【机器人管理】按需在本站重新启用原机器人，或添加机器人并在两站都启用，系统会自动恢复出报表；同时通知技术。服务机器人疑似封禁或 Token 失效时人员收不到任何回复（不会收到这句），按处理步骤或换 Token。
报表和平台报表的今日数据对不上？
机器人是实时数据，平台报表每 30 分钟统计一次，今日会有差异。昨日、前日应一致：用该站对应时区的日报表，子站下对该站、全网数据下对两站合计；仍不一致转技术。
昨日的数据和之前看到的不一样？
查询任何日期都按当时的绑定和用户当前所属代理统计。调整过绑定，或做过会员变更代理、直属会员转移、投注站用户转移，历史日数据会变；变更代理还会改变测试标识，全站和全网数据也会变。
报表不见了？
报表发出满 24 小时自动删除。重新查询即可。
