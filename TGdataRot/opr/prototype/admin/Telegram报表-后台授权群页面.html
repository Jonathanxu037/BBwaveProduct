规则批注

  1. 授权范围：只登记群；群授权并启用后，群里所有成员都能使用；只对本站生效。私聊机器人不返回数据。PRD 规则 N4 · F05-02 授权群
  2. 校验：群 ID 必须是以 -100 开头的负数，否则提示「群 ID 格式不正确」；已在名单中时提示「该群已在名单中」；群名称必填，1–30 字。PRD 规则 N31 · F05-02
  3. 编辑：群 ID 不能修改（要改就删除后重新添加）；可改群名称和状态。PRD 规则 N31 · F05-02
  4. 生效：添加、停用、删除保存后立即生效，从下一次操作起按新名单判断；已发出的报表仍按 1 小时自动删除。PRD 规则 N32 · F05-02
  5. 列表：默认按添加时间倒序，每页 20 条；筛选后回到第 1 页；删除后当前页为空时回到上一页。PRD 5.3 列表分页
