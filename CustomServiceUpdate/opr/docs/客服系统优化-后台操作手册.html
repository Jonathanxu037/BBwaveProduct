重要结论
  • 所有会话列表都显示身份和等级标签，默认按等级从高到低排，从上往下接待即可（PRD 3.2 规则 N4）。
  • 改选其他排序方式后按所选方式排，排序值相同的等级高的在前；改回「User level: Highest first」恢复按等级排（PRD 3.2 规则 N5）。
  • 「游客」是识别不出平台账号的联系人，接待时先核实账号（PRD 3.2 规则 N3）。

01身份和等级标签

位置与范围

左侧「Conversations（会话）」下的所有会话列表（全部会话的各页签、提到我的、我参与的、未处理、各渠道、各标签），标签在用户名后面；打开会话后标题处也有。查看权限沿用现有。

标签说明

标签含义排序位置
金色「VIP 3」有 VIP 等级的玩家，显示 VIP 当前等级（VIP 会员体系上线后才出现）最前，VIP 等级高的在前
蓝紫色「LV 12」普通会员等级（等级中心 Level Center），含 LV 0 新用户VIP 之后，等级高的在前
绿色「会员」有平台账号、但还没有会员等级所有有等级的玩家之后
灰色图标「游客」客服后台识别不出平台账号的联系人最后

02排序方式

默认顺序

默认「User level: Highest first」：VIP › 会员等级 › 会员 › 游客，同一等级按进线时间先来在前。新会话插到对应位置，不一定在最上面。

操作步骤

1
点会话列表标题右边的排序按钮「⇅」，打开排序弹窗。
2
在「Order by」里选排序方式：第一项「User level: Highest first」为默认，其他为原有方式（如 Last activity 最近活动）。
3
列表按所选方式重新加载；选其他方式时，排序值相同的等级高的在前。

列表跳动

按用户等级排序时，鼠标停在列表上列表不会重排，移开 2 秒后才按最新顺序刷新，避免点错会话。

常见问题

为什么有的高等级玩家显示「会员」？
等级从来没有同步成功过时显示「会员」；同步失败但以前同步过的，会沿用上次的等级。持续出现请转技术排查。
低等级玩家等了很久怎么办？
本版不做超时置顶。高峰期请客服主管关注列表底部的会话，必要时手动分配。
状态筛选（Open 等）变了吗？
没有，保持原样。

打开前台原型 ›　｜　查看自助问题优化 PRD

重要结论
  • 自助问题优化改的是前台客服对话窗，客服后台没有新增功能和配置（PRD 自助问题优化 0. 本迭代范围）。
  • 玩家点「我的充值没到账，怎么办？」后，客服后台会话里只显示这个问题，没有自动回复，也没有备注（PRD 自助问题优化 3.2 规则 N20）。
01 会话里看到什么 常见问题

01会话里看到什么

玩家端：对话里显示问题和最近交易卡片，点「查看订单」可看充值、提现记录并复制订单号。
客服后台：会话里只有玩家点的问题。玩家已看过最近交易，可直接请玩家发订单号，按现有流程核查。

玩家在订单页点「人工客服」，会回到原来的对话转人工，客服后台不会新增一条会话。

常见问题

会话里为什么只有问题，没有回复？
原来的自动回复已改为玩家端的最近交易卡片，后台不再显示自动回复。
玩家说点问题提示「操作过于频繁」？
这个问题 1 分钟内只能点一次，请玩家 1 分钟后再试，或直接点已收到卡片上的「查看订单」。
