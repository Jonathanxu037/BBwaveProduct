后台首页弹窗管理中心

【活动配置 › 首页弹窗管理中心】，本需求在 789Bingo、789Games、789Play 三个站的管理后台各新增一个这个菜单（带淡色光晕的是新增控件）。只有弹窗列表一页，不设页签；全局设置在列表上方，改动记入平台【日志管理 › 操作日志】。首页弹窗管理中心只管弹窗的状态（开 / 关）、未登录 / 登录状态下是否展示和显示方式、显示顺序、当日免打扰和全局设置；按钮跳转在活动中心各活动配置页的「事件触发信息」里配置。

规则批注

  1. 三站各自建模块：789Bingo、789Games、789Play 三个站的管理后台各有一个「首页弹窗管理中心」，各自配置、只对本站前台生效；页面里没有站点下拉，也不能跨站查看或切换，顶部和面包屑显示当前所在后台。演示时用右侧「查看哪个站的后台」切换，相当于换一个后台登录，研发不实现。PRD 规则 N3 · F10-01 三站各自独立的首页弹窗管理中心
  2. 来源活动可直达配置：弹窗列表「来源活动」显示该弹窗所属活动在后台的面包屑位置，点击进入该活动的配置页（活动内容和弹窗按钮跳转在那里配置）；没有配置页的（如系统类的开启通知引导）只显示位置、不能点。首页弹窗管理中心没有按钮跳转配置。PRD 规则 N1、N38 · F05-01 弹窗列表
  3. 状态与显示方式：列表只显示当前设置（状态：打开 / 关闭 / 常开；未登录 / 登录状态：「✓ 展示 · 显示方式」/「不展示」），不能直接操作，统一在「修改配置」里改。每个弹窗有「状态」开关，打开时前台按显示方式弹出，关闭时前台任何状态都不弹（只有合规弹窗常开、不能关闭，系统类「开启通知引导」等其他弹窗都可关闭；领取类关闭时二次确认）。状态打开后，未登录、登录两种状态分别勾选「展示」（不勾选则该状态不弹），勾选后选显示方式：每次进入页面、首次打开（登录：每次登录后；未登录：每次打开 App / 网站后）、每天首次打开、活动期间一次（活动有起止时间才可选）、永久一次。每个排队弹窗在未登录、登录两种状态下是否展示都由运营勾选决定；上线初始化按现网，现网在该状态下不弹的初始为不勾选。改动和顺序、全局设置一起保存。PRD 规则 N17 · F06-01 修改配置
  4. 不可选的选项：页面不显示弹窗分类。个别弹窗不提供的显示方式在下拉里置灰并写明原因（如无其他领取入口的领取类没有「永久一次」，没有起止时间的弹窗没有「活动期间一次」）；不提供当日免打扰的弹窗不显示这个勾选框。PRD 规则 N21 · F02-02 显示方式
  5. 修改配置：弹窗列表「操作」列点「修改配置」，打开该弹窗的配置表单，显示全部可配置项：状态、显示顺序、未登录 / 登录状态的显示方式和当日免打扰，并可点来源活动进入活动配置页；点「确定」后改动停在列表上，与列表其他改动一起点「保存」提交；改了显示顺序的，和列表上改数字一样翻到该弹窗所在页并高亮。合规弹窗只能「查看配置」。PRD 规则 N17、N51 · F06-01 修改配置
  6. 修改配置的布局：常规表单，从上到下为弹窗、来源活动、状态、显示顺序，未登录状态、登录状态各一行：「展示」勾选框 → 显示方式下拉 → 当日免打扰勾选框（只在登录状态这一行，活动、活动图、公告弹窗才有）。未勾选「展示」时显示方式不可选；无其他领取入口的领取类关闭状态或取消「展示」时，在对应行下方显示确认条，点「确定」才改，点「取消」保持原值。PRD 规则 N21、N23 · F06-01 修改配置
  7. 拖动排序：在弹窗列表里按住 ⋮⋮ 上下拖动，列表从上到下就是前台弹出顺序；登录、未登录两个状态按同一顺序弹（各自只弹勾选了「展示」的弹窗）；也可直接改显示顺序，用于跨页调整，超出范围放到最前或最后；拖到合规行、提示条行或表格外松开放回原位；按关键字筛选时不能拖动。PRD 规则 N51 · F05-01 弹窗列表
  8. 管理范围：只管理在首页弹出的弹窗：合规置顶组、普通队列弹窗和首页顶部邀请好友提示条。可能在任何页面出现的事件触发弹窗（充值 / 提款失败、实名认证结果、邀请奖励到账、专属奖励、VIP 升级 / 生日奖励、下载 App 引导）不在本菜单列出，按各自逻辑弹出；它们在首页出现时仍遵守「等合规组和当前弹窗关闭后再弹、不叠加」。PRD 规则 N1、N28 · F05-01 弹窗列表
  9. 系列弹窗：活动按玩家操作依次弹出的一系列弹窗（如首页转盘 → 结果弹窗 → 首充后在充值页的第 3 次转盘），本菜单只管第一个弹窗在首页的显示场景和顺序；后续弹窗按活动自身逻辑弹出，不列出、不占顺序、不计单次上限，事件在活动配置页「事件触发信息」里配置；负责任博彩人群按 N49 过滤。PRD 规则 N49、N52 · 合规 X03
  10. 合规置顶组只读：强制更新 → 21+ → 协议 → 责任博彩 → 登录后 KYC 提示，固定在最前；没有拖动手柄，按现网实际合规弹窗行数固定占显示顺序 1～N（本页演示为 5 行），普通队列从 N+1 起编；不能关闭，不能选显示方式。789Bingo 游客进站的 21+ 是合并的 Responsible Gaming 声明（无 ×，789Games 有 ×），21+ 行「查看配置」写明它覆盖 21+、协议、责任博彩三项；协议、责任博彩两行的来源写「现网写死，待前端确认」。PRD 规则 N10、N11、N16 · F01-01 组成顺序与只读展示
  11. 当日免打扰：只对登录状态提供，按弹窗逐个打开，上线时全部关闭。未登录状态不提供，游客按显示方式照常弹：游客没有账号，转化注册是首要目标，且按设备记录不可靠（清缓存、换浏览器即失效）。只有活动、活动图（素材）、公告弹窗，且登录状态显示方式为「每次进入页面」或「首次打开」时可用，改成其他显示方式或取消勾选「展示」时自动关闭；列表只显示开关状态，在「修改配置」里修改。PRD 规则 N24 · F02-05 当日免打扰
  12. 领取类保护：「无其他领取入口」的领取类弹窗不受单次上限约束、不提供当日免打扰；关闭状态或取消某状态的「展示」时在表单内显示确认条（确认文案为示意），确认条未处理时对话框「确定」置灰。PRD 规则 N23 · F02-04 领取类保护
  13. 全局设置：单次上限登录状态、未登录状态各一个，默认「不限」，可选 1～10 个；点按钮跳走后「回 Home 继续弹剩余 / 本次剩余不再弹」，初始值与现网一致。PRD 规则 N22、N25 · F06-02 全局设置
  14. 保存与生效：保存要 Google 验证码，保存前二次确认按 N43 列出全部改动：一个弹窗一行，多项改动用「；」分隔（如「亏损返利：显示顺序 13 → 6；登录状态 每次登录后首次打开 → 不展示」）；顺延的弹窗合并成一行「其他 N 个弹窗顺序顺延（被动调整）」，可展开明细；没有改动提示「没有改动」；保存后 5 分钟内全量生效；他人已先保存时提示「配置已被他人修改，请刷新后重新编辑」。PRD 规则 N43、N44 · F06-04 保存与生效
  15. 操作日志：本菜单不设操作日志页签，每次保存的改动（旧值 → 新值）统一记入平台现有的【日志管理 › 操作日志】，按平台日志模块的规则查看和保留。PRD 规则 N45 · F08-01 记入平台操作日志
  16. 权限与状态：只有查看权限时列表只读、不显示保存和拖动手柄；没有菜单权限看不到菜单。列表有加载中、暂无数据、加载失败（可重试）状态。PRD 5.1 菜单、角色与权限 · F10-03 菜单权限与保存校验
