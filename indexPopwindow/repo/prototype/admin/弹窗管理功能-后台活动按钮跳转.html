    规则批注

    1. 落点：事件跳转在弹窗来源菜单配置；活动类弹窗在活动中心该活动的「弹窗按钮跳转」页签；首页弹窗管理中心点「来源活动」可直接打开。素材、公告仍在原菜单。PRD 规则 N38 · F07-01 事件触发信息
    2. 事件触发信息：列出本活动全部弹窗里玩家能触发的事件：每个按钮、规则入口、结果弹窗按钮、SPIN 各一行，每组另加「点击关闭 ×」。同一活动调用多种弹窗样式时按样式分组（如新用户转盘：首页转盘、结果弹窗、首充后在充值页的第 3 次转盘），组头写弹出条件。首页顶部邀请好友提示条归首页弹窗管理中心（只用状态开关），在邀请好友活动里单独一组，不是弹窗，没有「点击关闭 ×」行。跳转类事件显示目的链接地址和跳转位置（点击后去的页面名称，随链接实时更新）；点击后执行活动逻辑的事件（抽奖、砸蛋、领取、补领、展开规则、关闭、合规 / 系统按钮）只显示触发逻辑，不配链接。事件清单以前端现网为准。PRD 规则 N29、N32、N38 · F07-01 事件触发信息 · 待确认 Q1、Q33
    3. 系列弹窗：活动按玩家操作依次出现的一系列弹窗，只有第一个弹窗在首页的显示场景和顺序由首页弹窗管理中心管理；后续弹窗（如结果弹窗、首充后在充值页的第 3 次转盘）按活动自身逻辑弹出，组头标「后续弹窗」；负责任博彩人群按 N49 过滤。PRD 规则 N49、N52 · F07-01 事件触发信息
    4. 目的链接地址：运营直接填写，路径均为示意，以本站系统页面清单为准。留空 = 只关闭弹窗；站内页面填系统页面清单里的路径（如 /user/walletbox），只能带清单为该页面登记的附加参数（如游戏大厅 ?cat=Slots），输入时下拉提示可填路径；本站域名的完整地址要改填站内路径；指定游戏 /game/厂商编码/游戏 ID（如 /game/JDB/14001，下拉显示游戏名称，只能填已开启且支持手机端的游戏）；活动详情 /promo/活动名；站外填 http:// 或 https:// 完整地址，须命中【系统管理 › 系统参数管理 › 注册登陆 › 合规】外部链接白名单（白名单只由合规负责人或超级管理员维护；命中规则见 N39：规范化后比对，域名部分含「@」的不命中，路径里的「@」如 tiktok.com/@账号 允许，网址前缀后只能紧跟「/」「?」「#」或结尾）。站内、站外链接的参数和路径都不能带邀请码、推广码、代理码或会员信息。H5 和 App 用同一个链接：站内路径由系统换成 App 页面，站外链接 H5 新窗口、App 外部浏览器打开。填错时该行标红并写明原因（报错原文见 N39），不能保存。PRD 规则 N33、N39 · F07-02 目的链接地址与校验
    5. 兜底：页面被技术停用后，用到它的事件前台按「只关闭弹窗」处理，再次保存本活动时该行标红「该页面已停用」，改链接或清空后才能保存；站外链接对应的白名单条目被删除后，已保存的这类链接前台按「只关闭弹窗」处理，再次保存本活动时该行标红「链接不在外部链接白名单内」，需改链接才能保存；页面待 App 确认时 App 只关闭弹窗；App 版本低于页面的最低 App 版本时打开首页。PRD 规则 N40、N41
    6. 按钮文案：留空用默认文案；上限 N 取默认文案长度和 20 中较大者，输入框下方显示「n / N」，超出标红「文案超过 N 个字符」；只能用英文字母、数字、常用英文符号和 ₱；默认文案含金额的必须保留 {amount}，所有按钮都不能另写金额（金额口径见 N34），否则标红「文案不能写金额」。PRD 规则 N34 · F04-02 按钮文案
    7. 保存与日志：保存要 Google 验证码，5 分钟内本站前台生效；改动记入平台【日志管理 › 操作日志】，他人已先保存时保存失败。PRD 规则 N43、N44、N45 · F07-01 事件触发信息
    8. 权限：沿用该活动菜单的查看 / 编辑权限；只有查看权限时全部只读。PRD 5.1 菜单、角色与权限 · F10-03 菜单权限与保存校验
