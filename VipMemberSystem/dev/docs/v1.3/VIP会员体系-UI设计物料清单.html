整理日期：2026-11-06（GMT+8）依据：v1.3 原型、需求开发PRD文档读者：UI 设计、开发、测试、产品

本清单列出 v1.3 设计交付项、沿用现网的界面和无需出图的说明项，供设计排期及交付核对。「状态 / 尺寸要求」是产品对可读性和可用性的要求；颜色、尺寸、动效等具体视觉效果以 UI 设计师最终确定的设计稿为准。规则依据见 PRD（规则编号、章节号可点击跳转）；各物料要覆盖的状态以 PRD 第 4 章表 1（等级卡）、表 2（详情弹窗）、表 3（奖金状态与前台显示）为准，本清单逐项列出。优先级：P0 上线必须；P1 上线前完成，可与 P0 分批交付；P2 沿用现网样式，只需核对或少量调整。
