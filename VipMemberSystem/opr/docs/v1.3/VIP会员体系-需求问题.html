E-10每月奖金按当月达到每月奖金标准的最高等级 k 发放v1.2
原始需求原文七：保级奖励每月发放一次，完成当前等级当月保级有效投注才能获得；原文未写明未保级时是否还发每月奖金。
需求现在的写法
  • 升级、保级、每月奖金分别核算。
  • 每月奖金按 k 级生成：k = 当月有效投注达到每月奖金标准的最高等级，不超过历史最高；k = VIP0 不发。

  • 与原文七「完成当前等级保级才能获得」不同，以用户决定为准。
已定：按 k 级发放（用户 2026-10-29 定；PRD 规则 N14 每月奖金等级 k、N15 未保级与降级、N16 降级后恢复、N17 VIP0）

E-16完成 KYC 时补发已达到等级的升级奖金；「KYC 限制」切换的处理v1.2
原始需求原文四：首次升级至对应 VIP 等级后立即获得升级现金奖励；C-11 KYC 要求：完成 KYC 才能享受权益；原文未写完成 KYC 后是否补发。
需求现在的写法
  • 「KYC 限制」开启：完成 KYC 时按累计定级，此前已达到的每个等级各补发一次升级奖金（按完成 KYC 时的配置生成待领取；命中风控则暂停发放）；未完成 KYC 期间的每月奖金和生日奖金不补；上线结算等级及以下不发。
  • 开启 → 关闭：不给之前因未完成 KYC 而未定级的玩家补发任何奖金；这些玩家按关闭时刻的累计定级，已达到的等级不发升级奖金、不弹窗（用户 2026-10-31 定）；之后新达到的等级照常发放。
  • 关闭 → 开启：未完成 KYC 的玩家等级冻结、未领取的奖金暂停；完成 KYC 后恢复冻结时的等级，不按累计重新定级（避免绕过月度结算的恢复规则）；冻结期间累计超过历史最高的，升到新等级并照常生成升级奖金。
已定：完成 KYC 时补发（用户 2026-10-29 定；PRD 规则 N23「KYC 限制开启」）
已定：开启改关闭不补发（用户 2026-10-31 定，Q50「KYC 限制开启改关闭时是否补发」，PRD 规则 N25「KYC 限制切换」）
已定：开启改关闭时未定级玩家立即按累计定级、不发升级奖金（用户 2026-10-31 定，Q51「KYC 限制开启改关闭时，未定级玩家的等级怎么处理」，PRD 规则 N25「KYC 限制切换」）
E-17不设奖金审核；风控暂停v1.2
原始需求原文四：升级奖励立即获得；原文未写审核和风控。
需求现在的写法
  • 不设审核：后台没有「强制审核」开关，奖金没有「待审核」「已通过」「拒绝」状态；三种奖金默认由玩家手动领取，领取即到账（用户 2026-10-29 定）；后台可按奖金类型设为自动领取（用户 2026-10-30 定）。
  • 风控暂停：账号冻结、自我排除、风险分 ≥ 70、禁止投注、临时冻结时等级照算，奖金暂停发放、不能领取、不发奖金通知（升级弹窗例外见下文），由运营放行（恢复待领取）或作废；风险分 40–69 按领取方式正常处理；停用、注销的账号不生成奖金、不参与结算，未到账的奖金全部作废。升级时照常弹平台现网升级弹窗，只显示恭喜升级和等级，不显示奖金行（用户 2026-10-31）。
  • 后台放行、补发、作废和等级表保存不设第二人审批；放行、补发、作废确认后直接执行，等级表确认后保存配置、重新开启时生效。
已定：① 不设审核（用户 2026-10-29 定、2026-10-31 维持，PRD 规则 N30「不设审核」，Q45「大额奖金是否设审核」）
已定：② 风控暂停的触发范围（用户 2026-10-30 定，Q12 风控暂停的触发范围）
已定：③ 不设第二人审批（用户 2026-10-31）
E-18VIP 体系关闭期间和再次开启v1.2
原始需求原文未写体系关闭。
需求现在的写法
  • 开关「VIP会员系统」同时控制前台：关闭时隐藏 VIP中心入口和页面。
  • 关闭期间：累计照常；停止升级、结算、生成新奖金和 VIP 通知（不弹升级弹窗、不补弹，不发待领取通知、站内信、推送和生日提醒），事后不自动补做（结算时间处于关闭状态的月份不自动结算，显示「未结算（系统关闭）」，运营可「重新结算」，生成每月奖金和生日奖金）。
  • 关闭时已生成未领取的奖金：确认框列出全部「待领取」，运营勾选的确认后直接到账并发已到账通知；未勾选的作废（「系统作废：系统关闭」），不能补发、不通知玩家；风控标签逐笔显示，玩家当前处于风控暂停的整行保持原状态，关闭期间放行的直接到账；被中止结算月份已生成的奖金不列入勾选、保持原状态；配置变更批次列入勾选，按勾选结果发放或作废；关闭确认框保持现有设计，何时关闭由运营判断（如结算日的第二天）。
  • 关闭后玩家点以前收到的 VIP 站内信、推送（关闭前和关闭期间发出的都算）只显示内容、不跳转；直接打开 VIP中心链接时回到平台首页（用户 2026-11-02，Q78「系统关闭后旧通知的跳转」）。
  • 再次开启：按最新配置对全部玩家重新核算等级（含之前全量重算被中止、未处理的玩家；月度结算被中止的仍须继续结算）：只升不降、已发放不追回，降级中的玩家不回升，历史最高同步；关闭期间玩家自己投注、充值达到的等级记「不发放（重新开启核算）」，不发升级奖金；因关闭期间下调门槛新达到的等级照常生成升级奖金（待领取），24 小时内可整批作废；因新增等级新达到的只按等级调整补偿处理，重算前历史最高那一级已领取的不再发；都不弹升级弹窗；不重新计 28 天。
  • 修改等级表（门槛、三种奖金、每月奖金标准、新增 / 删除等级）须先关闭「VIP会员系统」；关闭期间保存只做影响预览试算并保存配置，作废、重算、生成奖金在重新开启时统一执行。关闭期间可以「重新结算」、不能「继续结算」；关闭期间经过的结算时间点不自动结算，可由运营「重新结算」。等级表修改在重新开启时刻生效：关闭期间重新结算用旧配置，重新开启后才重新结算的用新配置。关闭前累计已达到、但因未完成 KYC 尚未定级的等级，重新开启时按 KYC 定级补发（用户 2026-11-02）。
  • 月度结算或等级重算进行中也可以关闭「VIP会员系统」（谷歌验证码 + 二次确认），关闭后中止当前任务，已结算玩家的等级和奖金照常有效（中止月份已生成的奖金关闭期间暂停领取，重新开启后有效期重新起算），中止的月度结算重新开启后可「继续结算」（不受 28 天限制），只结算未结算的玩家；还没到可领日的生日奖金不列入关闭时的勾选，关闭后作废。
已定：关闭期间玩家自己达到的新等级，重新开启后不发升级奖金；因门槛下调新达到的照常发（不弹升级弹窗，第 16 批 T02）（用户 2026-10-30 定，Q13 VIP 体系关闭后再次开启、Q44 再次开启重新核算等级）
已定：关闭时未领取奖金由运营勾选发放或作废，前台隐藏 VIP中心（用户 2026-11-02，PRD 规则 N27「VIP 体系关闭与再次开启」）
