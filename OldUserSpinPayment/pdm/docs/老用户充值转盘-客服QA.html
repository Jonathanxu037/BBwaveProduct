老用户充值转盘 · 客服 QALucky Spin · Customer Service Q&A

版本 / Version：v1.0适用 / For：客服 Customer Service依据 / Based on：PRD、后台操作手册 Admin Manual

适用范围 Scope

活动：老用户充值转盘（前台名称 Lucky Spin）。生效：本功能上线、运营在活动里勾选「原生Gcash」后适用；生效时间与现有选项一致。
Event: Lucky Spin for existing players. Effective: after this feature goes live AND Operations adds native GCash to the event. It takes effect the same way as the existing payment methods.

这次改了什么 What changed

运营现在可以在 Lucky Spin 活动的充值方式里勾选「原生Gcash」（对应原生 GCash 通道）。勾选后，老用户经该通道充值成功的，按现有规则获得转盘次数；未勾选时不获得。其他规则不变。是否给次数，以订单实际通道和活动规则为准。
Operations can now add native GCash (the native GCash payment channel) to a Lucky Spin event. Once added, existing players whose deposits through this channel are successful get spins under the existing rules. If it is not added, those deposits do not earn spins. All other rules stay the same. Eligibility follows the channel the order actually used and the event rules.

客服核查步骤 How to check

回复玩家前按顺序查，任何一步不满足，按规则不给次数。Check in this order before replying. If any step fails, no spin is given under the rules.

  1. 订单状态：在【财务管理 › 充值记录】查这笔订单是否充值成功。处理中或失败的订单不给次数。
    Order status: In 财务管理 › 充值记录 (Finance › Deposit Records), check whether the order is successful. Processing or failed orders get no spins.
  2. 实际通道：在同一条记录里看「支付渠道」和「付款方式」，确认这笔订单实际走的支付通道。
    Actual channel: In the same record, check 支付渠道 (Payment Channel) and 付款方式 (Payment Method) to confirm the channel the order actually used.
  3. 活动是否勾选：在【活动中心 › 老用户充值转盘】打开玩家充值时正在进行的活动，看「范围配置 › 充值方式」里有没有这笔订单的通道；原生 GCash 通道对应选项「原生Gcash」。
    Event payment methods: In 活动中心 › 老用户充值转盘 (Activity Center › Lucky Spin for existing players), open the event running at the deposit time and check 范围配置 › 充值方式 (Scope › Payment Methods). The native GCash channel appears as the option "原生Gcash".
  4. 金额和条件：金额、充值时间和玩家条件是否满足活动规则，以活动配置为准。
    Amount and conditions: Check whether the amount, deposit time and player conditions meet the event rules. Follow the event settings.
  5. 是否已发放：在活动的「活动统计」或玩家资金明细（类型「老用户充值转盘」）查有没有领取记录。
    Already credited? Check the event's 活动统计 (Statistics) tab or the player's 资金明细 (fund details) (type "老用户充值转盘") for a claim record.
  6. 转技术：以上都满足仍没有次数时，转技术排查。
    Escalate to Tech: If all of the above are met but there is still no spin, escalate to Tech.

问答 Q&A

1我用 GCash 充值了，为什么没有 Lucky Spin？I deposited with GCash. Why didn't I get a Lucky Spin?

回复玩家Reply
Thank you for reaching out. Lucky Spin chances are given based on the payment channel your order actually used and the event rules. Please share your order number and deposit time, and we will check it for you.
感谢联系。Lucky Spin 次数按订单实际使用的支付通道和活动规则判断。请提供订单号和充值时间，我们帮你查询。
客服核查Check
按「客服核查步骤」第 1～6 步（订单状态、实际通道、活动是否勾选、金额和条件、是否已发放、转技术）逐项查。
Go through steps 1–6 in "How to check" (order status, actual channel, event payment methods, amount and conditions, already credited, escalate to Tech).

2我之前用 GCash 充值的订单，能补 Lucky Spin 吗？Can I get a Lucky Spin for my earlier GCash deposit?

回复玩家Reply
Please share your order number and deposit time, and we will check whether this deposit meets the event rules.
请提供订单号和充值时间，我们帮你查询这笔充值是否符合活动规则。
客服核查Check
对比订单的充值成功时间和活动勾选「原生Gcash」的时间；生效时间与现有选项一致。之后的订单仍没有次数时，按问答 1「用 GCash 充值了为什么没有 Lucky Spin」处理。
Compare the order's success time with the time native GCash was added to the event. It takes effect the same way as the existing payment methods. If a later order still has no spin, follow Q&A 1 (deposited with GCash but no Lucky Spin).

3我的充值还在处理中 / 失败了，会给 Lucky Spin 吗？My deposit is still processing or failed. Will I get a Lucky Spin?

回复玩家Reply
Lucky Spin chances are given only after a deposit is successful. If your deposit is still processing, please wait for it to complete. Failed deposits are not eligible.
Lucky Spin 次数只在充值成功后给。充值还在处理中的，请等处理完成；充值失败的订单不参加活动。
客服核查Check
查订单状态。订单变为成功后仍没有次数时，按问答 1「用 GCash 充值了为什么没有 Lucky Spin」处理。
Check the order status. If it becomes successful and still has no spin, follow Q&A 1 (deposited with GCash but no Lucky Spin).

4以前的活动会自动加上原生 GCash 吗？Do earlier events include native GCash automatically?

回复玩家Reply
Eligible payment methods depend on each event. Please share your order number and deposit time, and we will check it for you.
参加活动的支付方式按每个活动的规则。请提供订单号和充值时间，我们帮你查询。
客服核查Check
不会自动加上。已有活动需要运营手动勾选「原生Gcash」，以活动的「充值方式」为准。
No. Operations must add "原生Gcash" to existing events manually. Follow the event's 充值方式 (Payment Methods).
