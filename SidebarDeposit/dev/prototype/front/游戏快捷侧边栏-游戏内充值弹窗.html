游戏内充值弹窗

入口：游戏页侧边栏的「充值」（Deposit）。本需求把原来的全屏充值改为充值弹窗：不退出游戏、游戏不刷新，内容沿用现有充值页（依据 Claire《游戏中半屏充值功能需求》）。原型分两页演示，实际是在同一个游戏页面上打开。带淡色光晕的是本需求新增的控件。

规则批注

  1. 打开：点侧边栏「充值」→ 侧边栏收起 → 充值弹窗从底部升起，高度固定为游戏页面高度的 2/3，不随内容变化，内容超出时在弹窗内滚动（小屏手机同样适用）；打开前不做游戏结算；游戏保留在底层不关闭、不刷新，上方加半透明遮罩不能操作；浮标贴到所在一侧的屏幕边，显示贴边状态的动图（仍然显示，不消失）。横屏时逻辑和竖屏一致（从底部升起、高度固定为游戏页面的 2/3、内容超出在弹窗内滚动、游戏保留在底层），具体布局由 UI 出横屏适配设计。PRD 规则 N14 · F07-01 打开与关闭充值弹窗
  2. 内容：支付方式、优惠活动（Promotions）券、充值金额、快捷金额、赠送和幸运转盘标签、限额、条款、提交全部沿用现有充值页，不新增配置；内容在弹窗内滚动，提交按钮固定在底部。优惠活动（Promotions）区和 Wallet 充值页同一位置、同一逻辑：首存和每日存送同时开启时只显示首存券；只有每日存送时显示每日存送券，玩家点券上的圆圈自行选择是否申请，再点取消，不申请也能充值；都没有存送活动时整个区换成普通标题语「继续游戏，精彩不停！」（英文 Keep the game going!），可在模拟面板切换。画面里的支付方式、金额和标签只是示意，以现有充值设置为准（HOT 角标按现状固定在 +200）。PRD 规则 N15 · F07-02 充值内容与提交
  3. 校验：没填金额、也没点快捷金额之前，提交按钮置灰不能点；点了快捷金额或输入金额后可点，清空金额后重新置灰。超出限额提示「请输入 100-50,000 之间的金额」（现有文案，数值随渠道变化）；提交中按钮置灰防重复。PRD 规则 N15 · F07-02 充值内容与提交PRD 8. 接口与异常 · F07-02
  4. 二维码支付：下单成功后弹窗收起，打开二维码支付页：H5 新开浏览器标签页，原游戏标签页保持打开；APP 用独立支付页、WebView 或外部浏览器（按支付方式现有的打开方式），原游戏页面保持。H5 支付页被浏览器拦截时弹窗保持打开，提示「支付页面打开失败，请重试」。支付页的有效期、提示文案和结果页按目前接入的三方支付流程和规则显示，原型文案只是示意。PRD 规则 N16 · F07-03 二维码支付与返回原游戏
  5. 返回原游戏：支付完成后回到原游戏，不跳大厅、不重新加载：H5 回跳到「支付完成」中间页，自动关闭新标签页回到原游戏标签页，浏览器不允许自动关闭时提示「请返回游戏页面，到账后余额会自动更新」并给「关闭此页面」按钮（中间页不知道订单结果，支付失败、取消或二维码过期后渠道也可能回跳到这里，所以文案保持中性，不写「支付已完成」）；在 TG / Facebook 内置浏览器、小程序或已安装的 PWA 中，支付页在系统浏览器打开，付完款中间页只显示文字、不提供进入平台的入口，玩家切回原 App / PWA 继续游戏（PRD 5.1）；回跳地址不带登录 token 和玩家身份信息（其他参数由技术按当前平台规则处理）；APP 打开支付页付款后要玩家手动切回 APP（现状，-2207 等）。不弹现有的「Payment Information」和「充值返回弹窗」，也不弹充值成功提示；游戏页内不弹到账推送，只进站内信；充值后触发的营销和引导弹窗（首充转盘、6954 充返转盘等）在玩家回到平台页面后才显示，达到后台「新用户强制 KYC 设置」投注笔数上限后的强制 KYC 等合规拦截照常在游戏内弹出；到账判定和入账按现有系统逻辑处理；到账后平台通知厂商把游戏内显示的余额刷新为充值后余额，不退出游戏；不支持刷新的厂商到账后自动刷新游戏页面（当前局未结算时等结算后再刷新；刷新前充值弹窗或客服对话窗正打开时，等玩家关闭后再刷新；只重新加载当前游戏，不重新做准入校验和各类引导，不播放小猫开车 loading 动画（显示现有 loading 页），不影响自动展开机会）；玩家充值后立刻离开当前游戏时，先离开结算再到账同步。PRD 规则 N16、N13 · F07-03 二维码支付与返回原游戏
  6. 首充后：新用户在充值弹窗里完成首充后，可以继续当前游戏，游戏页上不弹首充转盘和 PWA / APP 引导；关闭游戏回到平台原生页面后，再按平台规则显示。PRD 规则 N16
  7. KYC 提醒与首存券：未认证或 KYC 审核中的玩家输入金额或提交时，按现有充值 KYC 规则处理（受后台「系统参数 › 充值提款 › 实名验证」和 3 天规则控制），提醒显示在充值弹窗上方：现有规则允许「稍后」时，点「稍后」或右上角 × 只关闭提醒、留在弹窗，不自动提交，由玩家自己再点提交（这次打开弹窗内不再重复提醒）；现有规则阻断时（如注册满 72 小时仍未认证、充值要求实名）只显示「立即认证」，不能提交；KYC 审核中只显示「KYC 审核中」提示，不能提交（三种情况模拟面板可切换）。点「立即认证」先显示「正在结算游戏余额…」，结算同步后跳到 KYC 页，等同离开游戏（原型用「身份认证页」示意）。每次打开弹窗重新拉取优惠券资格，首充后不再显示首存券。PRD 规则 N15 · F07-02 充值内容与提交
  8. 关闭：点右上角 × 或点上方遮罩，立即关闭回到游戏；侧边栏为收起状态，浮标回到原位置完整显示；已填写的金额不保留；自动展开机会不变。弹窗打开期间浮标贴边显示（沿用游戏页记住的一侧和高度），点贴边的浮标 → 弹窗关闭、侧边栏展开。PRD 规则 N14、N5、N8 · F07-01、F03-02
